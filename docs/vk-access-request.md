# Запрос доступа к VK Музыке для Luma

**Статус:** черновик, не отправлен. Адрес для запроса расширенных прав — `devsupport@corp.vk.com`, из [документации VK для разработчиков](https://dev.vk.com/ru/api/privacy). Подтверждения, что VK выдаёт новому настольному клиенту доступ к Музыке, пока нет. Если за музыкальное лицензирование отвечает другая команда, попросите направить запрос к ней.

## Текст письма

**Тема:** Официальный доступ к VK Музыке для настольного Luma

Здравствуйте!

Разрабатываем [Luma](https://github.com/JohnBirlich/VKX-Modded), открытый плеер для Windows 10/11 x64. Сейчас он распознаёт музыкальные ссылки VK и открывает их на официальном сайте внутри окна приложения. Хотим узнать, можно ли подключить VK Музыку официально для собственного приложения Luma, не используя веб-сессии или идентификаторы других клиентов.

Просим уточнить условия и возможный порядок подключения для следующих сценариев:

1. **Вход.** Какой поток авторизации и callback поддерживаются для настольного Luma? Можно ли использовать вход с QR на стороне VK? Как выдаются и отзываются разрешения для самого приложения Luma?
2. **Метаданные.** Можно ли по согласию пользователя читать его фонотеку и плейлисты, получать метаданные записей по ссылке и выполнять поиск? Просим перечислить доступные методы, права, квоты, требования к отображению и хранению метаданных.
3. **Воспроизведение.** Можно ли воспроизводить полные треки внутри Luma? Какой официальный способ доставки или SDK предусмотрен, какие условия подписки, лицензии, регионов и атрибуции нужно соблюсти?
4. **Офлайн — отдельный запрос.** Предусмотрено ли разрешённое сохранение трека или плейлиста для прослушивания без сети? Если да, нужны условия срока хранения, проверки подписки, защиты локальной копии и удаления при отзыве доступа. Если нет, офлайн для VK не будет включён.
5. **Проверка.** Есть ли песочница или одобренный тестовый аккаунт с примерами разрешённого и ограниченного контента? Как зарегистрировать приложение Luma, подать его на проверку и согласовать лицензирование?

Подойдёт раздельный ответ по каждому сценарию: какие доступны, какие требуют договора, какие не поддерживаются. Просим не присылать пароли, токены или пользовательские данные по почте; для настройки тестового доступа подскажите защищённый канал.

Спасибо!

## Что нужно перед реализацией

Достаточно передать разработчику ссылку на разрешённую документацию, публичный ID зарегистрированного приложения Luma и перечень согласованных сценариев. Секреты и доступ к тестовому аккаунту настраиваются в защищённом окружении, не в чате, коммите или публичной задаче.

Упоминание `audio` в общем списке прав VK не подтверждает выдачу этого доступа для Luma. Параметр `offline` в том же списке относится к сроку действия ключа API, а не к разрешению сохранять музыку. Включать чтение, поток и офлайн нужно раздельно, только после подтверждения каждого сценария.
