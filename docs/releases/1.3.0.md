# Luma Player 1.3.0 · Windows x64

## Слушать внутри Luma

- **Главная → VK Музыка.** Откройте «Сегодня в плеере» или вставьте код либо ссылку официального виджета своего плейлиста. Нажмите ▶ в виджете. VK разрешает воспроизводить только **первые пять треков**; весь список открывается по кнопке «Весь плейлист на VK». Обычная ссылка на плейлист не заменяет код виджета. Вход в VK через Luma, поиск по каталогу и синхронизация фонотеки не добавлены.
- **Главная → YouTube.** Пять официальных аудиоверсий: Animal Sun, Тимати feat. Егор Крид, The Weeknd feat. Daft Punk, Баста и Алексей Воробьёв. Можно вставить свою ссылку на отдельную запись YouTube или YouTube Music и включить её во встроенном плеере. Luma не требует Premium, покупки или ключа API. Реклама и ограничения встраивания остаются.

Виджеты открываются только после выбора, используют управление источника и не меняют очередь Luma. Воспроизведение Luma ставится на паузу; при уходе с вкладки виджет закрывается. Доступность конкретных записей зависит от сервиса и региона. [Как пользоваться](https://github.com/JohnBirlich/VKX-Modded/blob/v1.3.0/docs/services-setup.md#vk-виджет-внутри-luma).

## Радио, поиск и интеграции

- **Радио → Поиск станций:** Radio Browser без аккаунта, с фильтрами по названию, стране, языку и тегу. Совместимые HTTPS-эфиры играют в Luma, остальные открываются на странице станции.
- **Поиск:** прямой Jamendo с вашим бесплатным Client ID дополняет выдачу Openverse без дублей Jamendo; Audius проверяет до 36 кандидатов за запрос. Результаты прямого Jamendo и Audius доступны в текущей сессии, без скачивания и офлайн-копий.
- **ListenBrainz:** независимо от Last.fm можно включить отправку прослушиваний локальных треков. Нужен User Token; отправка выключена по умолчанию, история в ListenBrainz публична.
- **Genius:** аннотации и ссылка на оригинальную страницу в данных трека после настройки токена. Genius не добавляет аудио или полные тексты в караоке.
- **Openwhyd:** импорт публичного плейлиста по ссылке. Luma сопоставляет записи с файлами в медиатеке и сохраняет только выбранные совпадения, не скачивая музыку.

[Настройка сервисов](https://github.com/JohnBirlich/VKX-Modded/blob/v1.3.0/docs/services-setup.md). Автоматические проверки виджетов используют тестовое аудио; воспроизведение реальных записей VK и YouTube зависит от сети, региона и разрешений сервиса.

## Загрузка

- **`Luma-Player-Setup-1.3.0-x64.exe`** — установка или обновление для Windows 10/11 x64. Закройте Luma перед обновлением.
- **`Luma-Player-Portable-1.3.0-x64.exe`** — запуск без установки с тем же профилем Windows.
- **`SHA256SUMS.txt`** — контрольные суммы обоих файлов. Сборки не подписаны; Windows может предупредить о неизвестном издателе.
