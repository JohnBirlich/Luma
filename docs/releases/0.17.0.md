# Luma Player 0.17.0 · Windows x64

- **Автопоиск на Главной и во вкладке «Поиск».** Введите запрос один раз. Luma ищет в медиатеке и после короткой паузы параллельно запрашивает Jamendo и Wikimedia Commons через Openverse, а также Internet Archive Netlabels и Southern City’s Lab. Результаты появляются по мере готовности. Если один каталог не ответил, остальные результаты сохраняются. Автопоиск можно выключить, чтобы запрос оставался на устройстве.
- **«Мои треки из VK».** В разделе **Главная → Моя музыка** можно импортировать CSV или TXT со списком треков. Названия, исполнители и альбомы сохраняются локально и находятся в поиске без сети. Если в медиатеке есть однозначное совпадение по тегам, из списка можно включить локальный аудиофайл. Для TXT используйте строки `Исполнитель — Название`; для CSV — колонки `title,artist,album` (альбом необязателен). Файл — UTF-8, до 2 МиБ и 10 000 записей.
- **Ссылки на музыкальные сайты** вынесены в свёрнутый блок. VK Музыка, Музыка Mail.ru, Яндекс Музыка, Zvuch, DriveMusic и Muzika.fun открываются только по нажатию и не входят в выдачу Luma.

**Синхронизации аккаунта VK и воспроизведения потоков VK в этом релизе нет.** Импорт переносит список, а не аудио. Сохранённые закладки VK и их обложки остаются в профиле.

## Загрузка

- **`Luma-Player-Setup-0.17.0-x64.exe`** — установка или обновление для Windows 10/11 x64. Перед обновлением закройте Luma.
- **`Luma-Player-Portable-0.17.0-x64.exe`** — запуск без установки с тем же профилем Windows.
- **`SHA256SUMS.txt`** — контрольные суммы файлов. Сборки не подписаны: Windows может показать предупреждение о неизвестном издателе.
