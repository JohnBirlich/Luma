# Luma Player 0.15.0 · Windows x64

## Что нового

- **Темы:** все пять оформлений применяются сразу и сохраняются после перезапуска. Ручной выбор отключает автоматическое расписание. **MacOS** перестраивает интерфейс в стиле Liquid Glass из iOS 26: плавающая навигация вместо боковой панели, отдельная панель плеера, полупрозрачные карточки и очередь.
- **Главная:** «Сейчас играет», миксы, поиск, треки, жанры, настроения, радио, обновления и закладки VK теперь в одном разделе. Отдельной вкладки «Музыка» больше нет; ранее выбранный запуск на ней открывает «Главную».
- **Караоке:** обложка остаётся небольшой плиткой рядом с текстом. На фоне караоке нет растянутой обложки или сцены. Синхронизация строк, перемотка и управление воспроизведением сохранены. В обычном полноэкранном плеере обложка на фоне по-прежнему доступна.
- **Виджет:** **Ctrl+Shift+R** открывает и закрывает виджет, пока окно Luma в фокусе. **Esc** также возвращает обычное окно. Переключение не перезагружает плеер и не сбрасывает позицию трека.
- **Параметрический эквалайзер:** 10 полос с настраиваемыми частотой, усилением, типом фильтра и добротностью Q. График показывает АЧХ с предусилением, а автозапас может снизить уровень при подъёме частот. Старые полосы и их настройки переносятся. EQ обрабатывает локальные файлы и демотреки; онлайн-потоки воспроизводятся без EQ.

**VK Музыка:** личная фонотека VK и её воспроизведение внутри Luma не подключены. Ссылки на плейлисты и сохранённые обложки по-прежнему доступны как закладки.

## Установка

- **`Luma-Player-Setup-0.15.0-x64.exe`** — установщик для Windows 10/11 x64. Перед обновлением закройте Luma.
- **`Luma-Player-Portable-0.15.0-x64.exe`** — запуск без установки. Portable использует тот же профиль Windows.
- **`SHA256SUMS.txt`** — контрольные суммы обоих файлов. Сборки не подписаны: Windows может показать предупреждение о неизвестном издателе.
