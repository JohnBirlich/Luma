# Luma Player 0.11.0

Обновление для Windows 10/11 x64 после версии 0.9.0. Закройте старую версию перед запуском нового установщика. Медиатека, настройки, обложки и закладки остаются в прежнем профиле.

- **Поиск и главная.** В «Найти в музыкальных сервисах» — один список: Jamendo и Wikimedia Commons. Luma сначала ищет в медиатеке, затем по кнопке или `Enter` при отсутствии локальных совпадений — в выбранном источнике. На главной появились похожие треки, открытия и история из вашей медиатеки, без передачи истории в VK.
- **VK Музыка.** Официальная страница открывается внутри главного окна Windows. Вход сохраняется в отдельной сессии, которую можно сбросить через **Настройки → Интеграции → VK Music** без удаления закладок. Поддерживаются прямые ссылки, ссылки «Поделиться» и публичный виджет. Личные треки, подборки и VK Микс остаются на стороне VK и не добавляются в очередь Luma.
- **Звук и воспроизведение.** Формат и битрейт локальных файлов, профили потоков Jamendo для обычной и лимитной сети, автозапуск и плавный переход между локальными треками. Очередь, повтор и перемешивание по умолчанию сохраняются; сохранение каждого можно отключить отдельно.
- **Тексты и MP3.** Чтение локальных текстов и поиск в LRCLIB. При включённом сохранении текстов новый разрешённый MP3 из Wikimedia Commons получает синхронный `.lrc` рядом и обычный текст в теге, если обе версии найдены. Существующие файлы не перезаписываются.
- **Окно и оформление.** `F` открывает плеер на весь монитор; `Esc` возвращает прежнее окно. Компактный плеер поверх окон предлагает пять фонов и не перезапускает звук. Добавлены автоматическая смена темы, выбор стартового раздела, полные счётчики и классический докбар. Обновлены Волны, Дождь, Неон и Фейерверк; добавление в избранное подтверждается анимацией сердца.
- **Данные трека.** Поиск по названию в Apple Music поддерживает кириллический вариант запроса. Распознавание по звуку работает при наличии ключа приложения AcoustID (`LUMA_ACOUSTID_CLIENT`): отпечаток вычисляется на устройстве, исходный файл не отправляется и не меняется.

Кеширование потоков, аппаратный Float-вывод, Last.fm, VK Recommendations и автоматическая подстановка обложек iTunes не входят в этот релиз. Язык и регион влияют на форматы данных и поиск, но не переводят интерфейс.

В **Assets** есть установщик, portable и `SHA256SUMS.txt`. Сборки не подписаны; Windows может показать предупреждение о неизвестном издателе.
