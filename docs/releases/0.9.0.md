## Luma Player 0.9.0 · Windows x64

### Музыка с устройства и из открытых каталогов

- В **Поиске** сначала показываются совпадения в вашей медиатеке. Нажмите **Искать онлайн**, чтобы найти открытые записи Jamendo и Wikimedia Commons через Openverse. Можно воспроизвести запись, поставить её в общую очередь и сохранить ссылку; рядом указаны автор, источник и лицензия.
- **Медиатека → Без сети** показывает файлы и встроенные треки. **Из интернета** — сохранённые ссылки. В **Перенос музыки** можно добавить ссылку на запись Openverse одного из поддерживаемых источников. Онлайн-аудио не скачивается; доступ к потоку зависит от источника. Эквалайзер и реакция на звук работают с файлами и демотреками.
- **Миксы** собираются в Luma из медиатеки, избранного или истории. Есть подборки по исполнителю и жанру, фильтр «Только без сети», запуск с выбранного трека, перемешивание и добавление в очередь. Альбомы и исполнители доступны и из медиатеки.

### VK Музыка

Раздел Luma для закладок и публичных плейлистов: поиск по сохранённым названиям, обложки и импорт ссылок или кода виджета. Сайт VK больше не открывается в окне приложения. Официальный виджет включается отдельной кнопкой, а вход — только на сайте в браузере. Личная библиотека VK, «Для вас» и VK Микс не синхронизируются с Luma.

### Оформление и диагностика

- Обновлены все восемь прежних фонов. Добавлены **Неон**, **Калейдоскоп** и **Дождь**. В быстрых настройках есть предпросмотр, яркость, темп и реакция на локальный звук; системное ограничение движения учитывается.
- Диагностика различает Windows 10, Windows 11 и Windows Server, показывает сборку и архитектуру приложения. В браузере выпуск Windows не угадывается при отсутствии данных.
- В Windows окну задано отображаемое имя **Luma Player** для оболочки. Как именно имя источника выглядит в стороннем виджете, определяет сам виджет. Хранилище медиатеки, очередь и пользовательские настройки остаются на прежнем месте.

Закройте старую версию перед обновлением. **Setup** устанавливает приложение, **Portable** запускается без установки. Сборки не подписаны; `SHA256SUMS.txt` содержит контрольные суммы обоих файлов.
