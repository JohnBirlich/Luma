# Luma Player 0.18.0 · Windows x64

- **Караоке.** На большом экране обложка и управление слева, текст справа; в узком окне блоки располагаются друг под другом. Активная строка следует за общим таймлайном, в том числе при перемотке. Меню справа сверху позволяет менять размер, толщину, интервал и выравнивание строк, выбирать источник, повторно искать в LRCLIB или вставить свой текст/LRC. Обычные тексты и издания Викитеки не получают вымышленных таймкодов.
- **Импорт плейлистов.** В **Главная → Моя музыка → Мои плейлисты → Импортировать** выберите источник, откройте файл и проверьте совпадения. Поддерживаются `Playlist*.json` из архива Spotify, текстовый экспорт Apple Music, совместимые CSV/TXT и локальные M3U/M3U8. Логотипы источников доступны без сети. По подтверждению сохраняются однозначные совпадения из медиатеки в порядке исходного списка. Импорт не меняет очередь, не входит в аккаунты и не скачивает треки.
- **Радио.** В каталоге 96 станций: у 73 настроен прямой эфир в Luma, у 23 — ссылка на страницу станции в браузере. Ещё 11 каналов Record и SomaFM остаются в отдельном блоке. Можно искать по названию и фильтровать по жанру и способу прослушивания. Сохранённые станции открываются в отдельном виде **Добавленные**, без повторов в одном списке. Доступность эфиров зависит от сети и вещателя.
- **Виджет в теме MacOS.** Новый компактный вид с матовым фоном, тремя цветными кнопками окна и обложкой рядом с управлением. **Ctrl+Shift+R** переключает режим без перезапуска воспроизведения, **Esc** возвращает обычное окно. Предпросмотр — в **Настройки → Интеграции**.
- **Меньше дублирующих пунктов.** Из **Меню** убран повторный импорт треков; добавление аудиофайлов осталось по **+**, **Ctrl+O** и перетаскиванием. Из **Моей музыки** убраны старые блоки «Мои треки из VK» и «Закладки VK» без удаления сохранённых данных профиля.

**Доступ к личной фонотеке и воспроизведение потоков VK Музыки не подключены.** Ссылка на сервис по-прежнему открывается во внешнем браузере по нажатию. Импорт плейлистов не заменяет синхронизацию аккаунта.

## Загрузка

- **`Luma-Player-Setup-0.18.0-x64.exe`** — установка или обновление для Windows 10/11 x64. Перед обновлением закройте Luma Player.
- **`Luma-Player-Portable-0.18.0-x64.exe`** — запуск без установки. Использует тот же профиль Windows, что и установленное приложение.
- **`SHA256SUMS.txt`** — контрольные суммы обоих файлов. Сборки не подписаны, поэтому Windows может показать предупреждение о неизвестном издателе.
