## Luma 1.5.4

- **Исправлен режим «Без панелей».** В **Главная → VK Музыка → Вид страниц VK Музыки → Без панелей** скрываются левое меню, общая шапка VK и правый список чатов, даже когда VK размещает его отдельно от каталога. Музыкальный плеер, вкладки, поиск музыки и подборки остаются.
- Режим учитывает разные варианты настольной разметки VK. **Обычный вид**, **Только профиль**, вход и управление воспроизведением в Luma не изменились.
- [Отдельное Chrome-расширение VK Music Only 1.9.1](https://github.com/JohnBirlich/VKX-Modded/tree/v1.5.4/vk-extension) использует тот же файл стилей. Luma не загружает скрипты расширения. Скачивание треков не возвращено.

### Windows 10/11 x64

- **Luma Setup** — `Luma-Player-Setup-1.5.4-x64.exe`, обновляет существующую установку с сохранением профиля.
- **Luma Portable** — `Luma-Portable-1.5.4-x64.exe`, запуск без установки.
- В Luma 1.5.2 и новее подходящий файл можно скачать через **Главная → Обновления**. После загрузки закройте Luma и запустите файл вручную. Сборки не подписаны; контрольные суммы — в `SHA256SUMS.txt`.
