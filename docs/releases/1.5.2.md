## Luma 1.5.2

- **Скачивание обновления прямо в Luma.** В **Главная → Обновления** и в настройках версии, если доступен более свежий стабильный выпуск, Luma предлагает подходящий файл: Portable для Portable, Setup для установленной версии. Видно, сколько уже скачано; загрузку можно отменить.
- После проверки размера и SHA-256 файл сохраняется в отдельной папке в Windows **Загрузки**. Кнопка **Открыть папку** показывает его. Закройте Luma и запустите скачанный файл вручную. Скачивание не закрывает плеер, не перезаписывает запущенный `.exe` и не меняет профиль. Подписанный установщик по-прежнему требует подтверждения и проверки закреплённого сертификата для запуска из Luma.
- Переход на 1.5.2 с более ранней версии выполняется по-старому; новая кнопка пригодится для следующих обновлений.

### Windows 10/11 x64

- **Luma Setup** — `Luma-Player-Setup-1.5.2-x64.exe`, обновляет прежнюю установку и сохраняет профиль Luma.
- **Luma Portable** — `Luma-Portable-1.5.2-x64.exe`, запуск без установки.
- Контрольные суммы — `SHA256SUMS.txt`. Сборки не подписаны.
