# Luma Player 0.14.0 · Windows x64

- **Караоке**: большая обложка, данные записи и управление слева; справа — строки, подсвечиваемые по времени текущей записи. В узком окне панели складываются вертикально. Для обычного текста без таймкодов подсветка не имитируется.
- **Внешний вид**: тема **MacOS** со светлыми стеклянными панелями, фоновая обложка без примеси выбранного ранее эффекта, переработанный **Солнечный ветер**, плавный жидкий фон микса Luma с учётом настройки движения.
- **Виджет**: добавлены обложка альбома, матовое стекло, северное сияние и тёплый свет. **Ctrl+Shift+M** переключает виджет, пока Luma в фокусе; **Esc** возвращает обычное окно. Движок не меняется и трек не перезапускается.
- **Настройки**: одна стрелка «Назад»; названия треков и подписи интерфейса не выделяются при нажатиях и перетаскивании. В полях и тексте песен копирование работает.
- **Last.fm**: ввод ключей прямо в настройках, защищённое хранение, отдельное согласие на скробблинг. Код `11` показывает временную недоступность API, а не ошибку аккаунта. Реальная авторизация зависит от ответа Last.fm.
- **Windows**: имя приложения и файла (`LumaPlayer.exe`) согласованы с источником медиасессии. Папка профиля, адрес локального интерфейса и идентификатор обновлений установщика остались прежними. Отображаемое имя в стороннем виджете зависит и от его распознавания источников.

Треки VK не подменяются открытым каталогом: для нативной аудиотеки и воспроизведения нужен доступ к музыкальному API, предоставленный VK. Обычный VK ID его не выдаёт; закладки и их обложки сохранены.
