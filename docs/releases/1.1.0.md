# Luma Player 1.1.0 · Windows 10/11 x64

Караоке с подсветкой по словам и новый поиск данных о записи. Для этих функций не нужны API-ключи или платная подписка.

## Что нового после 1.0.0

- **«Сейчас играет» и «Караоке».** Luma выделяет текущее слово по таймкодам LRCLIB, если они есть для этой записи. Подсветка следует за воспроизведением и перемоткой. Если доступны только строки LRC или обычный текст, Luma использует их и не придумывает метки слов. Локальные `.lrc` и `.txt` по-прежнему работают.
- **Поиск текста.** Если точный запрос не находит текст, Luma делает один резервный поиск и принимает только однозначное совпадение. Для синхронизации сверяются название, исполнитель и длительность с допуском до 2 секунд. Конечный `!` в имени исполнителя не мешает совпадению — например, `Руки Вверх` и `Руки вверх!`. Автопоиск по умолчанию выключен.
- **Данные трека → Найти данные записи → MusicBrainz.** Для локального трека можно сравнить версии по длительности, изданиям, году и ISRC, если он есть. Поиск запускается вручную и не отправляет аудио. Вставленные данные можно проверить до нажатия **«Сохранить»**; исходный файл не меняется. MusicBrainz бесплатен для некоммерческого использования и предоставляет метаданные, не аудио.

Jamendo и Wikimedia Commons по-прежнему доступны через Openverse. Новых источников потокового аудио нет: Audiomack и SoundCloud не подключены, VK остаётся доступен через браузер и импорт готовых списков.

## Загрузка и обновление

- **`Luma-Player-Setup-1.1.0-x64.exe`** — установщик. Закройте Luma и запустите Setup поверх прежней версии. Профиль остаётся в `%APPDATA%\Luma Player`; не нужно удалять старую версию или заново добавлять музыку.
- **`Luma-Player-Portable-1.1.0-x64.exe`** — запуск без установки. Закройте прежний Portable и замените `.exe`. Профиль хранится в Windows, не рядом с файлом.
- **`SHA256SUMS.txt`** — контрольные суммы обоих файлов. В PowerShell: `Get-FileHash -Algorithm SHA256 .\Luma-Player-Setup-1.1.0-x64.exe`. Для Portable подставьте его имя.

Сборки не подписаны. Luma может показать, что доступна новая версия, но скачивание и установка выполняются вручную со страницы релиза.
