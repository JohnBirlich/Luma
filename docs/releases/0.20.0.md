# Luma Player 0.20.0 · Windows x64

## Плейлисты и поиск

- **Импорт с проверкой каждой строки.** Перед сохранением можно оставить найденный файл, выбрать другой трек из медиатеки или пропустить запись. Порядок сохраняется, очередь не меняется. Импорт работает с файлами экспорта, без входа в сервисы.
- **Поделиться и добавить в избранное.** `.luma.json` передаёт только метаданные треков, без аудио и путей к файлам. Получатель открывает его через «Импорт из сервисов → Luma». Треки плейлиста можно добавить в «Любимое Luma», не меняя лайки в других сервисах.
- **Одна запись, несколько источников.** Поиск группирует совместимые локальные и онлайн-версии, показывает их источники и сохраняет историю подтверждённых запросов на устройстве. Блок «Источники» можно свернуть, а автопоиск — выключить, оставив ручной онлайн-поиск.
- **Audius в Windows.** Публичные треки можно проигрывать и добавлять в очередь текущей сессии. Скачивание, офлайн-копии и сохранение в плейлисты Luma не поддерживаются. Jamendo, Wikimedia Commons и Internet Archive остаются в поиске.

## Воспроизведение и оформление

- **Таймер сна** доступен на карточке «Сейчас играет» и в настройках воспроизведения. **Синхронный текст** позволяет перейти к строке кликом или с клавиатуры.
- **Локальная копия при сбое.** Если включить эту настройку и онлайн-поток не запускается, Luma может переключиться на единственный найденный файл с тем же ISRC и совместимыми метаданными. Настройка выключена по умолчанию.
- В оформлении появились **«Тоннель» и «Столбцы»**, обновлены «Призма» и «Переливы Luma». В теме Glass сохранён отдельный стеклянный док; эффект «Жидкое стекло» не окрашивается под обложку.

## Интеграции Windows

- **Discord Rich Presence** выключен по умолчанию. Для отображения названия и исполнителя нужен запущенный Discord Desktop и публичный Application ID в настройках интеграций. Токен бота не нужен.
- **Музыкальные ссылки.** Setup регистрирует `luma-player://`. Карточка ссылки открывается без автозапуска. Поддерживаемые записи Openverse можно открыть в Luma по подтверждению; VK и Яндекс Музыка пока распознаются и открываются только во внешнем браузере. Вход в VK, синхронизация фонотеки и офлайн VK не добавлены.
- **Проверка обновлений** на Главной и в настройках версии. Этот выпуск не подписан: Setup и Portable обновляются вручную. Установка из приложения требует подписанной сборки с закреплённым сертификатом и подтверждения пользователя.

Это промежуточный выпуск Windows, не 1.0.0. Отдельные проверки на установленной Windows и требования к внешним интеграциям перечислены в [чек-листе 1.0.0](https://github.com/JohnBirlich/VKX-Modded/blob/v0.20.0/docs/windows-1.0-readiness.md).

## Загрузка и обновление

- **`Luma-Player-Setup-0.20.0-x64.exe`** — для Windows 10/11 x64. Перед обновлением закройте Luma и запустите Setup. Версия использует прежнюю папку профиля Windows.
- **`Luma-Player-Portable-0.20.0-x64.exe`** — запуск без установки. Использует тот же профиль и не регистрирует обработчик ссылок.
- **`SHA256SUMS.txt`** — контрольные суммы обоих файлов. Сборки не подписаны; Windows может показать предупреждение о неизвестном издателе.
