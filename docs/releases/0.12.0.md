## Luma Player 0.12.0 · Windows x64

- Русский и английский интерфейс переключаются без перезапуска. Настройки запоминают раздел и возвращают к прежней вкладке и позиции прокрутки.
- Пять новых жанровых демотреков, доработанные фоны и полноэкранный плеер с очередью. Дизлайк исключает запись из подборок Luma, не удаляя её из фонотеки.
- Поиск Jamendo, Wikimedia Commons, Internet Archive Netlabels и лейбла Southern City’s Lab. Разрешённые Commons MP3 можно кэшировать для прослушивания без сети; сохранение копии в выбранную папку остаётся отдельным действием.
- Локальные `.lrc` и `.txt`, синхронные теги MP3 и отдельные тексты из Викитеки. Поиск совпадающей записи через LRCLIB остаётся доступен.
- Скробблинг Last.fm после подключения API-аккаунта и отдельного согласия. [Пошаговая настройка](https://github.com/JohnBirlich/VKX-Modded/blob/v0.12.0/docs/services-setup.md). Личные рекомендации VK открываются на официальной странице VK; Apple используется для метаданных.
- Опциональный WASAPI Exclusive Float32 для локальных файлов при поддержке драйвером. Не гарантирует bit-perfect; совместимость проверяется на вашем устройстве.

**Файлы:** установщик и portable для Windows 10/11 x64. Обе сборки используют профиль Luma Player; portable не переносит профиль рядом с `.exe`. Проверить целостность файлов можно по `SHA256SUMS.txt`.
