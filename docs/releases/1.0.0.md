# Luma Player 1.0.0 · Windows 10/11 x64

Самостоятельный плеер для локальной музыки, открытых каталогов, радио и караоке. **VK в этом выпуске работает через внешний браузер и импорт готовых файлов**: входа в аккаунт из Luma, поиска по VK, воспроизведения и офлайна VK внутри плеера нет.

## Что изменилось после 0.20.0

- **Импорт из сервисов → VK Музыка.** Если у вас уже есть CSV или TXT со списком треков, откройте его и проверьте совпадения с медиатекой. Luma не запрашивает фонотеку и не открывает ссылки из файла.
- **Импорт из сервисов → Unison.** Из резервной копии JSON версии 1 можно выбрать плейлист или «Любимое Unison», проверить совпадения и сохранить список локально. История, настройки, ссылки и идентификаторы сервиса из копии не переносятся. Сетевой синхронизации и отправки лайков в другие сервисы нет.
- **Проверка настоящих Setup и Portable в Windows CI.** Setup открывает карточку музыкальной ссылки `luma-player://` при закрытом и при запущенном плеере, без автозапуска трека. Проверены переустановка той же версии с сохранением профиля и удаление только собственной регистрации. Portable использует прежний профиль и не регистрирует обработчик ссылок.

Поиск по медиатеке и открытым каталогам сохраняется: Jamendo и Wikimedia Commons через Openverse, Internet Archive Netlabels и Audius. Треки Audius доступны в текущей сессии, без скачивания, офлайн-копий и сохранения в локальные плейлисты. VK и Яндекс Музыка открываются во внешнем браузере. Каталоги VK, Яндекс Музыки, YouTube и SoundCloud не подключены.

## Проверки и ограничения

Модульные тесты, дымовые тесты Electron, проверка пакетов и запуск установленных сборок прошли в Windows CI. Отмена экспорта и запись в выбранный путь с кириллицей проверены с подменой выбора файла. Системный буфер обмена и нативный диалог «Сохранить как», физические медиаклавиши, экран блокировки, конкретное аудиоустройство и Discord Desktop требуют отдельной ручной проверки. Discord Rich Presence выключен по умолчанию; проверен с тестовым IPC, не с реальным клиентом. Android в этот выпуск не входит.

Сборки не подписаны, установка обновлений из приложения недоступна. Проверка новой версии работает, а скачивание и установка выполняются вручную. [Чек-лист Windows и требования к внешним интеграциям](https://github.com/JohnBirlich/VKX-Modded/blob/v1.0.0/docs/windows-1.0-readiness.md).

## Загрузка и обновление

- **`Luma-Player-Setup-1.0.0-x64.exe`** — установщик для Windows 10/11 x64. Для обновления закройте Luma и запустите Setup поверх прежней версии, не удаляя старую. Папка профиля не меняется: `%APPDATA%\Luma Player`. Если нужна резервная копия, скопируйте эту папку при закрытом плеере; исходные аудиофайлы лежат отдельно.
- **`Luma-Player-Portable-1.0.0-x64.exe`** — запуск без установки. Закройте прежний Portable и замените `.exe`; данные остаются в профиле Windows, а не рядом с исполняемым файлом.
- **`SHA256SUMS.txt`** — контрольные суммы обоих файлов. В PowerShell выполните `Get-FileHash -Algorithm SHA256 .\Luma-Player-Setup-1.0.0-x64.exe` или подставьте имя Portable. Windows может показать предупреждение о неизвестном издателе; скачивайте файлы из этого релиза.
