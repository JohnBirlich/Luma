# VK Next и VK Music Saver в Luma

Эти расширения **не включены**. Сам факт, что VK работает в Chromium, не означает, что его расширения из Chrome Web Store можно поставить в Luma.

- [Документация Electron](https://www.electronjs.org/docs/latest/api/extensions) описывает загрузку только распакованных расширений, в постоянную сессию и при каждом запуске. Набор поддерживаемых API ограничен; совместимость с произвольными расширениями из магазина не гарантируется.
- [VK Next](https://chromewebstore.google.com/detail/jephanpkonkmnkekmlkcijdjgniikppl) меняет не только проигрыватель, но и страницы, интерфейс и сообщения VK. Его код работал бы в профиле, в котором пользователь входит в VK. Для поставки нужна проверяемая версия с понятной лицензией, точным списком разрешений и аудитом кода, выполняемого на страницах VK.
- [VK Music Saver](https://chromewebstore.google.com/detail/ijgkbcbalaekboipcmaefchfjpognmog) в основном скачивает записи и плейлисты, а также может подбирать тексты через Genius. [Сборка для Firefox](https://addons.mozilla.org/en-US/firefox/addon/vk-music-saver/) помечена MIT и запрашивает доступ к страницам VK и `api.genius.com`; это не подтверждает совместимость или лицензию конкретной Chrome-сборки. Публичный GitHub-репозиторий с соответствующим выпуском не найден. Загрузка файлов из VK-гостя в Luma отключена.

Для этой интеграции не расширяем разрешения гостя, не разрешаем скачивание и не даём расширениям доступ к странице входа. Перемотка и переключение используют плеер VK независимо от расширений.

[VK Music Only](../vk-extension/) из этого репозитория — отдельное расширение для Chrome. Оно меняет только вид поддерживаемых страниц VK Музыки, не скачивает записи и не перехватывает запросы. Luma не загружает это расширение: **Без панелей** в приложении — встроенный режим.
