# Как подключить музыкальные сервисы с нуля

Для локальной музыки, демотреков, поиска открытых записей и поиска названия в каталоге Apple ключи не нужны. Для VK можно войти на официальном сайте внутри Luma без создания API-приложения. Настройки ниже относятся к настольной сборке с соответствующими функциями, а не к веб-превью или к более старым релизам.

## Last.fm: создать ключ, подключить аккаунт и проверить скробблинг

1. Создайте обычный аккаунт на [Last.fm](https://www.last.fm/join) и войдите на сайт. Откройте [Create API account](https://www.last.fm/api/account/create).
2. Укажите имя приложения, например `Luma Player (personal)`, и цель: запись прослушиваний с вашего согласия. Если нужен сайт приложения, укажите [репозиторий](https://github.com/JohnBirlich/VKX-Modded). Для [настольной авторизации](https://www.last.fm/api/desktopauth) Luma не принимает callback от браузера: вы подтверждаете доступ на сайте и завершаете подключение в плеере. После регистрации понадобятся **API Key** и **Shared Secret**. Пароль от Last.fm в Luma вводить не нужно.
3. Полностью закройте Luma. В PowerShell запустите плеер с ключом и секретом. Подставьте путь к **своему** установочному `Luma Player.exe` или portable `.exe`; команды спросят значения отдельно, секрет не отобразится при вводе:

   ```powershell
   $exe = 'C:\путь\к\Luma Player.exe'
   $env:LUMA_LASTFM_API_KEY = Read-Host 'Last.fm API Key'
   $secret = Read-Host 'Last.fm Shared Secret' -AsSecureString
   $env:LUMA_LASTFM_SECRET = [System.Management.Automation.PSCredential]::new('Luma', $secret).GetNetworkCredential().Password
   try {
     Start-Process -FilePath $exe
   } finally {
     Remove-Item Env:LUMA_LASTFM_API_KEY, Env:LUMA_LASTFM_SECRET
     Remove-Variable secret
   }
   ```

   Для запуска из исходников выполните `npm.cmd run dev` в том же терминале **вместо** `Start-Process -FilePath $exe`. Переменные передаются дочернему процессу, а не записываются в настройки Windows. Для последующих запусков используйте те же ключ и секрет: обычный ярлык без этих переменных не сможет отправлять запросы Last.fm. Не добавляйте секрет в скрипт, репозиторий, отчёт, скриншот или чат.
4. Откройте **Настройки → Интеграции → Last.fm → Подключить Last.fm**. Разрешите доступ только на открывшейся странице `www.last.fm`, вернитесь в Luma и нажмите **Завершить подключение**. Появится имя аккаунта. Если показано **Создать API-аккаунт**, Luma запущена без подходящих переменных: закройте её и проверьте шаг 3.
5. Отдельно включите **Отправлять прослушивания в Last.fm**. Запустите локальную запись с заполненными полями «исполнитель» и «название», длительностью более 30 секунд. Прослушайте не меньше половины записи или 4 минут (что наступит раньше) без перемотки. Проверьте список прослушиваний в своём профиле Last.fm. Сообщение «сейчас играет» и скроббл — разные запросы. Демо и сайт VK не отправляются.
6. Чтобы остановить передачу, выключите переключатель. **Отключить Last.fm** также удаляет сессию из Luma. Если нужно отозвать доступ на стороне сервиса, откройте [Last.fm Settings → Applications](https://www.last.fm/settings/applications). Сессия хранится в зашифрованном хранилище ОС, если оно доступно; иначе её надо подтвердить заново после закрытия Luma. Доступ к сети нужен в момент отправки: офлайн-очереди скробблов нет.

## VK: моя музыка и рекомендации

1. Нажмите **VK Музыка → Открыть сайт VK в Luma**. Войдите на официальной странице VK и перейдите в «Моя музыка», микс или рекомендации на самом сайте. Сохранённые ссылки на плейлисты можно открывать там же; публичный виджет работает отдельно и не получает ваш вход.
2. Для нативного доступа из очереди Luma потребуется **письменное разрешение VK** на нужные методы и музыкальные права. Начните с [официальной документации VK для разработчиков](https://dev.vk.ru/ru) и канала поддержки VK. Опишите настольное приложение, авторизацию и точный сценарий: личная библиотека, персональные рекомендации, воспроизведение. Уточните доступность документации, OAuth-разрешений, стран, лицензии на воспроизведение и правил хранения для каждого сценария. Создание обычного приложения и получение его ID не дают такой доступ автоматически.
3. Пока подтверждённого доступа нет, используйте официальный сайт. Не копируйте токены или cookies из браузера и не подставляйте ключи другого приложения. Luma не использует закрытые музыкальные методы и не сохраняет потоки VK.

## Тексты: что доступно сейчас и как запросить Musixmatch

1. Для файла `song.mp3` положите рядом `song.lrc` (с таймкодами) или `song.lyrics.txt` (простой текст UTF-8). Поддерживаются также теги MP3 USLT и SYLT с миллисекундными таймкодами. В **Сейчас играет → Текст песни → Открыть .lrc / .txt** можно временно подставить свой файл для текущей записи. Исходные теги и файлы не меняются.
2. **Найти текст** ищет совпадения в [LRCLIB](https://lrclib.net/docs) по данным записи. Для нескольких песен доступен отдельно отмеченный оригинал из Викитеки: это текст издания, а не расшифровка конкретного исполнения. Права на аудио и текст нужно проверять отдельно, даже при сохранении новой копии MP3.
3. Если нужен каталог Musixmatch, начните с [документации и контактов для интеграции](https://docs.musixmatch.com/enterprise-integration/implementation-guidelines). Укажите продукт, регионы, показ обычных и синхронных текстов, экспорт и желаемое хранение. Подтвердите у поставщика, какие функции разрешены, и согласуйте лицензию и реквизиты доступа. Отдельно проверьте обязательную атрибуцию, ссылки, счётчик просмотров и региональные ограничения. Не извлекайте тексты с сайта в обход API. Musixmatch в плеере пока не подключён, а полученный ключ сам по себе не добавит эту интеграцию.

## Apple: уточнение метаданных, а не загрузка чужих обложек

1. Выберите локальный трек → **Редактировать данные трека → Найти данные записи → По названию**. Ключ не нужен. Сверьте исполнителя и длительность, затем вставьте данные и подтвердите сохранение. Страница результата открывается в Apple Music. Для поиска по звуку используется отдельный [ключ приложения AcoustID](https://acoustid.org/new-application), переменная `LUMA_ACOUSTID_CLIENT`.
2. [Условия iTunes Search API](https://developer.apple.com/library/archive/documentation/AudioVideo/Conceptual/iTuneSearchAPI/Searching.html) ограничивают использование промоматериалов. Для допустимого промоблока с обложкой нужно отдельно проверить условия, поставить неизменённый [официальный бейдж Apple](https://marketing.services.apple/itunes-identity-guidelines) рядом и вести прямо на страницу покупки соответствующей записи. Это не разрешение сохранять картинку в теги, профиль или фонотеку. Luma получает метаданные и ссылку; не подставляет обложки и не играет превью Apple. Для своей обложки используйте файл, на который у вас есть права.

## Реальный Float-вывод: Windows 10/11 и совместимый драйвер

1. В Windows выберите нужные динамики/ЦАП устройством вывода по умолчанию. В дополнительных свойствах этого устройства разрешите приложениям использовать монопольный режим, если такой параметр есть. Закройте программы, которые уже заняли устройство. Если собираете Luma сами, установите [Visual Studio Build Tools](https://visualstudio.microsoft.com/downloads/) с компонентами **Разработка классических приложений на C++**, компилятором MSVC x64 и Windows SDK; затем запустите `npm.cmd run build:native`. В готовую сборку входит `LumaFloat.exe`.
2. В Luma откройте **Настройки → Качество аудио → Попробовать Float-вывод**. Запустите локальный файл. Статус **WASAPI Exclusive · IEEE Float32** означает, что вспомогательный процесс успешно открыл устройство в стерео Float32 на частоте аудиографа Luma и запустил вывод. Это не выбор 24-битного целого режима, не настройка аудио в VK и не гарантия bit-perfect. Декодирование, преобразование к частоте аудиографа, громкость, кроссфейд и эквалайзер остаются на стороне плеера; драйвер/ЦАП могут использовать другой внутренний формат.
3. Если появляется сообщение о занятости или несовместимости, Luma возвращается к системному выходу, если он доступен. Если системного устройства нет, плеер сообщает об этом. Поддержка Float32 в общем режиме Windows не означает поддержку того же формата в монопольном режиме. Проверьте драйвер и устройство по умолчанию или просто выключите переключатель. В веб-превью такого выхода нет. Проверка на Windows без вашего устройства не подтверждает слышимый звук на вашем ЦАП.
