# VK Music Only

Отдельное расширение для Chrome 136 и новее. **Без панелей** разворачивает поддерживаемую настольную страницу VK Музыки на всю ширину. Оно скрывает общее меню и шапку VK, оставляя штатный музыкальный плеер и содержимое каталога. Цвета задаёт VK. Снимите флажок в меню расширения, чтобы вернуть исходный вид без перезагрузки.

Эффект работает только на распознанных страницах VK Музыки на `vk.ru` и `vk.com`. Расширение не перенаправляет с ленты, профиля или входа и не скачивает треки. Разрешение `storage` нужно только для сохранения переключателя.

## Установка

1. Откройте `chrome://extensions` и включите **Режим разработчика**.
2. Нажмите **Загрузить распакованное расширение** и выберите папку `vk-extension`.
3. Если обновляете старую версию, нажмите **Обновить** у расширения и перезагрузите уже открытые вкладки VK.

Luma не загружает расширение. Встроенный режим **Без панелей** использует тот же файл `styles.css`, но не браузерные скрипты или разрешения расширения.
