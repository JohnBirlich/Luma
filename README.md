# Luma Player

Аудиоплеер для Windows на Electron, React и TypeScript. Локальная медиатека и пять встроенных демотреков работают без интернета и аккаунта. Во вкладке **VK Музыка** можно открыть официальный сайт с аккаунтом или выбрать плейлист для встроенного виджета. Обложки из файлов подхватываются автоматически, оформление и поведение плеера можно настроить под себя.

## 1. Запуск с нуля на Windows

### Готовый установщик — без Node.js и Git

Скачайте один из `.exe` в разделе **Assets** на странице [последнего релиза](https://github.com/JohnBirlich/VKX-Modded/releases/latest). Для промежуточных сборок используйте архив **Luma-Player-Windows-x64** из успешного запуска **Actions → Windows build**.

| Файл | Что делать |
| --- | --- |
| `Luma-Player-Setup-0.7.0-x64.exe` | Запустите установщик, выберите папку и откройте **Luma Player** через меню «Пуск». Устанавливается для текущего пользователя. |
| `Luma-Player-Portable-0.7.0-x64.exe` | Запустите напрямую, без установки. Настройки и медиатека всё равно сохраняются в профиле Windows, а не рядом с `.exe`. |

Цель сборки — **Windows 10/11 x64**. Интерфейс Luma и установщик — на русском; системные окна выбора файлов используют язык Windows. Для обновления закройте старую версию и запустите новый установщик. Приложение использует тот же профиль Windows, что и предыдущие версии: медиатека, очередь, сохранённые плейлисты и настройки не сбрасываются. Сборки не подписаны: Windows может предупредить о неизвестном издателе. Используйте файлы из релизов этого репозитория, доверенного запуска Actions или своей сборки. Точную версию запущенной копии можно посмотреть в **Меню → О приложении**.

### Запуск из исходников и сборка своих `.exe`

1. Установите [Node.js 22 LTS](https://nodejs.org/) (версию **22.12 или новее** в ветке 22.x). Установите [Git](https://git-scm.com/download/win), если будете клонировать, а не распаковывать ZIP.
2. Скачайте исходники из ветки **`main`** и распакуйте их. То же самое можно сделать через PowerShell:
   ```powershell
   git clone --single-branch --branch main https://github.com/JohnBirlich/VKX-Modded.git
   cd VKX-Modded
   ```
3. Откройте PowerShell в папке с `package.json` и выполните:
   ```powershell
   node --version
   npm.cmd ci
   npm.cmd run dev
   ```
   Откроется приложение Electron. Интернет нужен при установке зависимостей и первой загрузке Electron, не для прослушивания локальных файлов. `npm.cmd` работает и там, где PowerShell блокирует запуск `npm.ps1`.
4. Чтобы собрать установщик и portable, закройте окно разработчика и выполните:
   ```powershell
   npm.cmd test
   npm.cmd run dist:win
   ```
   Оба `.exe` появятся в **`release/`**. `npm run build` выполняет проверку типов и сборку, а `npm start` запускает собранную версию из исходников без Vite.

Если порт `5174` занят, перед `npm.cmd run dev` задайте, например, `$env:LUMA_DEV_PORT = '5184'`. Если `npm ci` не видит Node.js сразу после установки, переоткройте терминал. GitHub Actions также собирает `.exe` при отправке ветки или открытии PR.

## 2. Проверка без установки: веб-превью

Откройте живое превью **Luma Player** в Arena. Для запуска браузерной версии у себя:

```sh
npm ci
npm run dev:web
```

Откройте адрес из терминала (обычно `http://localhost:5173`). Веб-версия воспроизводит те же демотреки и принимает ваши файлы. Сайт VK открывается в новой вкладке браузера; встроенные виджеты работают, если браузер может их загрузить. Веб-превью не тестирует кнопки окна Electron, поведение установленной программы и интеграцию с Windows. Если хранилище браузера доступно, файлы остаются у текущего браузерного профиля в IndexedDB; при запрете хранилища или недостатке места они доступны до закрытия вкладки. Загрузки на сервер нет.

## 3. Что проверить

1. Нажмите **Воспроизвести**: должен заиграть `Отблеск`, а ползунок — пойти вперёд. Поставьте на паузу, перемотайте, проверьте громкость и отключение звука.
2. В **Очереди** перетащите следующий трек за его номер или поменяйте порядок кнопками `… → Выше / Ниже`. Проверьте удаление из очереди, перемешивание и переключение повтора: выкл. → вся очередь → один трек.
3. Откройте **Эквалайзер**. Выберите пресет, отрегулируйте пять полос и предусиление во время воспроизведения. Переключатель позволяет сравнить звук с обработкой и без неё.
4. Нажмите **Добавить музыку** или перетащите в окно несколько аудиофайлов. В **Медиатеке** или **Поиске** найдите трек по названию, исполнителю или альбому. Luma автоматически показывает обложку из тегов файла. Если подходящей картинки нет, появятся фирменные наушники. Если отсутствует название, используется имя файла. Кнопка **Демотреки** скрывает или возвращает встроенную коллекцию.
5. Откройте редактор обложки и поменяйте картинку у текущего трека во время воспроизведения. Обложка должна обновиться, а музыка — продолжить играть с прежней позиции.
6. На экране **Сейчас играет → Оформление** выберите винил и эффект. Запустите трек и откройте его во весь экран: обложка, перемотка, смена трека и пауза должны работать без перезапуска звука. Проверьте совпадение версии в **О приложении** и **Диагностике**.
7. В **Меню → Настройки** выберите тему, измените вид экрана **Сейчас играет** и задайте стартовую страницу. Закройте и снова откройте приложение: оформление, обложки, медиатека, очередь, громкость и эквалайзер должны остаться. В Windows дополнительно проверьте сворачивание, разворачивание окна и медиаклавиши во время активной сессии воспроизведения.

На Windows командой `npm.cmd run test:desktop` после `npm.cmd run build` можно проверить кириллицу, версии, обложки, полноэкранный режим и журнал в реальном Electron с временным профилем. Изоляция окна VK проверяется с тестовой страницей без аккаунта. Этот тест также выполняется в CI.

Поддерживаемые расширения при импорте: **MP3, WAV, FLAC, OGG/OGA, OPUS, M4A, AAC и WEBM**. Воспроизведение зависит от аудиокодека, а не только от расширения; для первой проверки лучше использовать MP3 или WAV.

| Клавиши | Действие |
| --- | --- |
| `Ctrl+O` | Добавить музыку |
| `Ctrl+,` | Открыть настройки |
| `Ctrl+Shift+L` | Открыть диагностику |
| `Пробел` или `K` | Воспроизвести / пауза |
| `←` / `→` | Перемотка на 5 секунд по умолчанию; шаг можно изменить |
| `M` | Отключить или вернуть звук |
| `Q` | Показать / скрыть очередь |
| `F` | Развернуть / свернуть текущий локальный трек |
| `Esc` | Выйти из полноэкранного плеера |

Горячие клавиши воспроизведения работают, когда фокус вне полей ввода и кнопок. Медиаклавиши и метаданные для ОС передаются через Chromium Media Session при активном воспроизведении; Windows сама выбирает активный плеер, если их несколько. Luma передаёт название, исполнителя и квадратную обложку; внешний док решает, как их показать. Если док читает другой плеер, Luma не меняет его данные.

## 4. Меню, данные треков, обложки и настройки

**Главная**, **Поиск**, **VK Музыка**, **Медиатека** и **Меню** — пять основных разделов. На узком экране они находятся внизу. В медиатеке **С устройства** показывает только добавленные файлы. Список и плитка переключаются рядом с кнопкой воспроизведения.

Обложку не нужно выбирать после импорта: Luma читает встроенное изображение из аудиотегов. Если изображения нет или оно не открывается, показывается локальная картинка с наушниками в стиле логотипа. Она работает без интернета.

Luma читает названия файлов и теги на кириллице, исправляет типичные ошибки кодировки старых MP3 и ищет без учёта регистра и различия между «е» и «ё». Если в тегах действительно записано `Ty Zdes'` или другое название латиницей, оно не переводится автоматически.

- **Сейчас играет → карандаш** или карандаш рядом с локальным треком в **Медиатеке**. Измените название, исполнителя или альбом и нажмите **Сохранить**. Например, можно заменить `Ty Zdes'` на `Ты здесь`. Данные обновятся в Luma и системной медиасессии без перезапуска музыки. **Вернуть исходные** удаляет правки. Аудиофайл не меняется.
- **Сейчас играет → Обложка**, либо иконка картинки в строке или карточке трека в **Медиатеке**. Выберите или перетащите **JPG, PNG или WebP до 20 МБ**. В редакторе показана квадратная обрезка по центру; нажмите **Сохранить обложку**. Картинка обновится в Luma и системной медиасессии. **Вернуть исходную** восстановит встроенную обложку файла или стандартное оформление, если обложки в тегах не было.
- **Настройки → Внешний вид**: четыре темы, готовые акценты, произвольный цвет и переключатель анимаций. В разделе **Сейчас играет** выбираются компоновка и фон, а также цвет из обложки или акцента темы. Изменения видны сразу в предпросмотре. При системной настройке «уменьшить движение» анимации также отключаются.
- **Настройки → Воспроизведение**: стартовая страница, шаг перемотки клавишами (5, 10, 15 или 30 секунд), автоматический переход к следующему локальному треку. Видимость демотреков и формат списка находятся в разделе **Медиатека**. При выключенном автопереходе выбранный повтор одного трека продолжает работать.
- **Сбросить настройки** возвращает оформление, параметры запуска и воспроизведения, уведомления и интеграции, а также вид медиатеки и видимость демотреков по умолчанию. Пользовательские обложки и данные треков, любимые треки, история, музыкальные файлы, громкость и эквалайзер не сбрасываются. Обложки можно вернуть по одной в редакторе.

Пользовательские обложки и данные треков хранятся в локальном профиле Luma. Плеер не записывает их в аудиофайлы и не загружает в интернет. Если хранилище недоступно, Luma предупреждает, что изменение действует только до закрытия приложения или вкладки.

### Фоны и быстрый доступ

На странице **Сейчас играет → Оформление** можно сочетать четыре компоновки (обложка, размытие, винил, обложка в центре) с **Сиянием**, **Волнами**, **Звёздами**, **Спектром**, **Орбитами**, **Призмой**, **Импульсом**, **Туманностью** или фоном без эффекта. Яркость, темп анимации и реакция на локальный звук регулируются независимо, а предпросмотр показывает и фон, и выбранную компоновку. Фоны реагируют на частоты локального аудио; винил вращается только во время воспроизведения. В паузе, в скрытой вкладке и при отключённой анимации фон в плеере остаётся статичным. Настройка также доступна через **Настройки → Сейчас играет**.

Кнопка **Во весь экран** на карточке трека и в нижнем плеере (или клавиша **F**) открывает большой вид по мотивам примера в `Assets`: обложка, название и исполнитель, перемотка, избранное, транспорт и настройки звука. Стрелка вниз и `Esc` возвращают в обычный плеер без остановки музыки. **Далее** показывает фактическую очередь с учётом перемешивания и повтора: нажмите на строку, чтобы перейти к треку, или скройте список кнопкой вверху. На узком экране список под управлением плеера. В **Настройки → Сейчас играет** можно выбрать, показывать ли «Далее» при входе, и открывать ли плеер на весь монитор. Если хост не разрешает полноэкранный режим, плеер занимает окно или превью.

Сердце рядом с треком или кнопкой воспроизведения добавляет его в **Избранное**. Из обновлённой боковой панели можно открыть **Избранное**, **Очередь**, **Эквалайзер** и **Диагностику**. Кнопка рядом с «Коллекция» сворачивает панель до иконок. На узком экране **Избранное** и **Диагностика** находятся в **Меню**.

### Дополнительные настройки

- **Звук и эквалайзер**: общая громкость и редактор эквалайзера. Локальные файлы не перекодируются.
- **Уведомления**: можно скрыть подтверждения успешных действий. Ошибки по-прежнему отображаются.
- **Интеграции**: отдельно отключается передача названия, исполнителя и обложки в системную медиапанель. Здесь же есть ссылка на официальный вход VK.
- **Хранилище**: количество файлов, история локального воспроизведения и переход в журнал. **Меню → Недавно слушали** показывает до 60 разных треков, которые действительно начали играть. Запись истории можно выключить, а список — очистить отдельно от медиатеки и избранного.
- **Горячие клавиши**: справка с фактическими командами. **Обновления приложения**: номер установленной сборки и ссылка на релизы GitHub; установка запускается вручную.

### Диагностика и журнал

Откройте **Меню → Диагностика** или нажмите **Ctrl+Shift+L**. Экран показывает версию Luma, ОС и среду выполнения, состояние подключения и последние 300 событий запуска, загрузки медиатеки и виджета VK, импорта и воспроизведения. Статус сети относится к устройству, а загрузка фрейма VK не подтверждает доступ к самому плейлисту. Есть фильтр по разделу и кнопка **Только сбои**.

В Windows журнал сохраняется как `%APPDATA%\Luma Player\logs\diagnostics.json` (для разработки используется `Luma Player Dev`), в браузере — в локальном хранилище. **Сохранить .log** и **Скопировать отчёт** экспортируют все записи. **Очистить журнал** не затрагивает музыку и настройки. Записываются заранее определённые события, числовые коды, длительность операций и количество файлов. Пути, URL, токены, имена файлов и названия треков в журнал не попадают; автоматической отправки нет.

## 5. VK Музыка

**С аккаунтом:** нажмите **VK Музыка → Войти в VK в браузере**. Настольная версия передаёт `https://vk.ru/audio` браузеру по умолчанию, веб-версия открывает новую вкладку. Войдите на сайте VK, где находятся «Моя музыка», «Для вас» и VK Микс. Доступ зависит от VK, аккаунта и региона. Luma не принимает данные входа и не копирует личные треки или рекомендации.

**Отдельное окно сайта** — дополнительный вариант в настольной версии. У него свои cookies, и вход из браузера не переносится в окно или виджеты. Если VK отказывает во входе в отдельном окне, используйте основной вариант в браузере. Если ошибка возникает уже на официальном сайте в браузере — это не вход в Luma.

**Плейлисты без подключения аккаунта к Luma:**

1. В разделе **Плейлисты в виджетах** выберите **«Сегодня в плеере»**: его состав меняется на стороне VK.
2. Для своего плейлиста скопируйте ссылку из VK. Вставьте её в поле **«Ссылка на плейлист»** в [официальном генераторе виджета](https://dev.vk.ru/ru/widgets/playlist) и скопируйте предложенный **код для вставки**.
3. В Luma нажмите **+** рядом с заголовком **Плейлисты**, вставьте код, укажите название по желанию и нажмите **Сохранить плейлист**. Список сохраняется в вашем профиле Luma.

Виджет позволяет прослушать до пяти треков из доступного плейлиста. На доступ влияют настройки VK, регион и авторизация. Если VK просит войти либо плейлист не загружается, используйте **Плейлист в VK**. Обычный аккаунт не даёт Luma доступа к личной библиотеке VK через публичный API. В Luma не нужно вводить пароль, куки или токен. Сохраняются название и параметры виджета, а не аудио.

В настольном приложении Luma автоматически пытается показать обложку открытого плейлиста из публичного превью VK, без cookies и токенов. Если VK не выдаёт изображение, Luma показывает наушники. Кнопка рядом с **Плейлист в VK** позволяет выбрать свою картинку. Обложки отдельных треков загружает сам официальный виджет: Luma не может прочитать или заменить их внутри. В веб-превью картинки из VK доступны в виджете; вне виджета показывается обложка Luma или выбранное вами изображение.

Звуком VK управляет его собственный плеер; локальные очередь, горячие клавиши, эффекты и эквалайзер Luma на него не распространяются. При переходе на вкладку VK локальный трек ставится на паузу.

## Где хранятся данные

В настольной версии `%APPDATA%\Luma Player` содержит индекс `library.json`, кеш обложек из тегов, настройки и локальное хранилище пользовательских обложек. Режим `npm run dev` использует отдельную папку `%APPDATA%\Luma Player Dev`. Музыка остаётся в исходных папках. Удаление трека из медиатеки не удаляет его с диска; если файл перемещён, добавьте его заново с нового места. Для полного сброса закройте плеер и переименуйте соответствующую папку профиля. В веб-версии для сброса очистите данные сайта, на котором открыт плеер.

## Публикация релиза

1. Обновите версию в `package.json` и `package-lock.json` через `npm version <версия> --no-git-tag-version` и добавьте `docs/releases/<версия>.md`.
2. После слияния PR дождитесь успешного **Windows build** для этого коммита в `main`.
3. В **Actions → Publish Windows release** запустите workflow из `main` и передайте ID успешной сборки. Он проверит точное совпадение коммита, создаст тег `v<версия>` и опубликует проверенные установщик, portable и контрольные суммы.

## Структура проекта

- `src/` — интерфейс, транспорт, Web Audio, очередь и адаптер локальной библиотеки. Официальный виджет VK находится в изолированном iframe и не получает доступ к локальным данным.
- `electron/` — окно, импорт тегов, локальный индекс и выдача аудио с поддержкой перемотки. Рендерер работает без Node.js, через ограниченный IPC-мост. Официальное окно VK в `vk-window.ts` использует отдельную сессию без доступа к мосту Luma.
- `Assets/` — присланные скриншоты как ориентир для навигации и меню, а также иконка Windows. Примеры не включаются в приложение и не используются как элементы интерфейса.
- `.github/workflows/windows.yml` и `electron-builder.yml` — сборка Windows x64 и получение двух установочных файлов.
- `npm test` — автоматические тесты очереди, импорта, локальной выдачи аудио, обложек, миграции настроек и валидации виджетов VK. `scripts/make-demos.py` — исходник оригинальных демонстрационных сигналов; Python и FFmpeg нужны только для их регенерации.
