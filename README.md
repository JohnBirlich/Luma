# Luma Player

Плеер для **Windows 10/11 x64**: локальная медиатека, музыкальные подборки, открытые каталоги, прямые эфиры и караоке. Музыкальные подборки и «Сейчас играет» находятся на **Главной** и используют общий плеер и очередь. Luma не подключается к личной аудиотеке VK и не воспроизводит потоки VK.

**[Скачать 1.2.0](https://github.com/JohnBirlich/VKX-Modded/releases/tag/v1.2.0)** · [Что нового](docs/releases/1.2.0.md) · [Настройка сервисов с нуля](docs/services-setup.md)

В 1.2.0 **Радио** заменило вход в VK в быстром доступе. Добавлены обычные тексты Lyrics.ovh, поиск метаданных и миниатюр TheAudioDB и концертный архив Phish.in. Подсветка слов LRCLIB и MusicBrainz из 1.1.0 сохранены.

## Установка

| Файл из Assets | Как запустить |
| --- | --- |
| `Luma-Player-Setup-1.2.0-x64.exe` | Установите для текущего пользователя и запустите **Luma Player** из меню «Пуск». |
| `Luma-Player-Portable-1.2.0-x64.exe` | Запустите без установки. Данные сохраняются в профиле Windows, не рядом с `.exe`. |
| `SHA256SUMS.txt` | Сверьте SHA-256 нужного `.exe` с `Get-FileHash -Algorithm SHA256 .\имя-файла.exe` в PowerShell. |

Сборки не подписаны; Windows может показать предупреждение о неизвестном издателе. Скачивайте из релизов этого репозитория. Для обновления закройте Luma и установите новую версию: тот же профиль сохранит медиатеку, обложки, плейлисты, очередь и настройки. Установленная версия — **Меню → О приложении**. Русский и английский переключаются в **Настройки → Внешний вид**. Язык данных (форматы и магазин Apple) настраивается отдельно.

## Музыка и медиатека

- **Главная → Для вас.** Под карточкой «Сейчас играет» запустите микс Luma или настройте его по коллекции, избранному или истории; можно ограничить подборку файлами. Ниже — свои треки, жанры и настроения, а за ними подборки Luma и рекомендации из медиатеки. Откройте карточку, чтобы прослушать подборку, добавить результаты Jamendo или сохранить плейлист. Приложение использует реальные теги и локальную историю; не угадывает отсутствующие жанры и не добавляет вымышленную историю или друзей. «Не рекомендовать» исключает трек из подборок, но не удаляет его из коллекции.
- **Импорт из сервисов.** Кнопка на Главной рядом с **Добавить музыку** открывает мастер импорта плейлиста: выберите источник, откройте файл экспорта и проверьте совпадения. Для каждой строки выберите доступный трек или пропустите её. Плейлист сохраняется только по подтверждению. Вход в аккаунт и скачивание аудио не выполняются.
- **Моя музыка / Обновления.** Создавайте и редактируйте локальные плейлисты в «Моей музыке». В «Обновлениях» — проверка новых релизов и недавно импортированные файлы. Установка из приложения требует подписанной сборки; portable и неподписанные версии обновляются вручную.
- **Поиск на Главной или отдельная вкладка «Поиск».** Один запрос ищет в медиатеке и подключённых каталогах. В веб-версии и Windows это Jamendo и Wikimedia Commons через [Openverse](https://openverse.org/). В Windows также доступны Internet Archive Netlabels (включая подборку Southern City’s Lab) и [Audius](https://audius.co/). Для концертных записей [Phish.in](https://phish.in/api-docs) введите `Phish` и точное название песни, например `Phish Llama`. Совместимые записи показываются вместе с вариантами источника. Ввод с Enter и выбранные результаты добавляются в очищаемую локальную историю поиска. Выдача обновляется по мере поступления ответов; один сбой не скрывает другие записи. В компактном блоке **Источники** можно проверить статусы, а переключатель **Автопоиск** оставляет поиск по устройству и ручной онлайн-запрос. [Условия и ограничения источников](docs/services-setup.md#радио-поиск-по-каталогам-и-плейлисты).
- **Радио.** Ярлык под эквалайзером, в стеклянном доке и в заголовке узкого окна открывает **Главная → Радио** без запуска эфира. В каталоге 96 станций в заданном порядке, плюс каналы Record и SomaFM отдельным блоком. Ищите по названию и жанру: **В Luma** — прямой поток, **В браузере** — ссылка на эфир у источника. Кнопка **+** сохраняет станцию без запуска эфира. **Добавленные** — отдельный вид каталога, чтобы сохранённая станция не появлялась на экране дважды. При прослушивании **Предыдущая / Следующая** или **←/→** переключают прямые эфиры по кругу в порядке всего каталога, пропуская станции без потока. Посещённые станции не накапливаются в очереди. Поток идёт напрямую от вещателя; перемотки внутри эфира, кэша, экспорта, текстов и скробблинга нет.
- **Медиатека.** Добавляйте файлы кнопкой или перетаскиванием: MP3, WAV, FLAC, OGG/OGA, OPUS, M4A, AAC, WEBM. Воспроизведение зависит от кодека. Локальные файлы не загружаются на сервер и не копируются в Windows. Доступны список/плитка, избранное, до 60 недавних записей и **Без сети** для локальных файлов и демо. Обложка и правки названия/исполнителя сохраняются в профиле, не в исходном файле.
- **Онлайн-записи.** Можно слушать и ставить в очередь без добавления в медиатеку. У поддерживаемых источников можно сохранить ссылку в **Из интернета**; Audius и Phish.in доступны только в текущей сессии. **Перенос музыки → Импорт онлайн-трека** принимает ссылки Openverse на поддерживаемые источники. Jamendo: MP3 96 кбит/с, MP3 VBR или вариант каталога, отдельный профиль для лимитной сети. Другие источники — оригинал. Для разрешённых MP3 Wikimedia Commons в Windows доступен временный кэш (32 МиБ на трек, 128 МиБ суммарно, до 14 дней). Копию можно слушать без сети из **Из интернета**; очистка кэша не удаляет ссылки.

- **Обмен, избранное и воспроизведение.** Кнопка «Поделиться» сохраняет трек или список в файл `.luma.json` без аудио и приватных путей, а у поддерживаемой записи Openverse копирует ссылку для Luma. В «Моих плейлистах» можно перенести треки в «Любимое Luma» без изменения лайков в других сервисах. Таймер сна доступен на карточке «Сейчас играет», Discord — по желанию в настройках интеграций.

### VK Музыка

Ярлык входа в VK удалён. Файловый импорт списков из VK и Unison не изменился.

В 0.18.0 блоки **Мои треки из VK** и **Закладки VK** убраны из «Моей музыки». Обновление не удаляет старые данные профиля. Если у вас уже есть CSV или TXT со списком треков, откройте его через **Импорт из сервисов → VK Музыка**. Мастер сопоставляет записи с медиатекой, не читает фонотеку аккаунта VK и не скачивает аудио. Кнопка ссылки на Главной принимает ссылки на треки и плейлисты VK и Яндекс Музыки. Luma пока может распознать их, но не проиграть без доступа к каталогу. [Что нужно для нативной интеграции и что используют неофициальные клиенты](docs/services-setup.md#vk-моя-музыка-и-рекомендации).

## Караоке и оформление

Нажмите микрофон на карточке трека или в нижнем плеере. **Караоке** ставит обложку и управление слева, а текст — справа. В узком окне колонки складываются. Выбранная сцена может оставаться на фоне, а режим «Обложка» заменяется мягким фоном. В теме **MacOS** это относится и к большому плееру. Доступны исполнитель, таймлайн, транспорт, громкость, очередь и эквалайзер. При наличии меток времени выделяется текущая строка, а если LRCLIB вернул точные метки слов — и текущее слово. Нажмите на строку, чтобы перемотать к ней. В **Настройках текста** можно выключить автопрокрутку, изменить размер, толщину, интервал и выравнивание. Оформление сохраняется между запусками. Текст можно выделить и скопировать; подписи меню, боковой панели и кнопок не выделяются.

| Источник текста | Что делает Luma |
| --- | --- |
| Соседний `.lrc`, `.lyrics.txt` или теги файла | В Windows читает соседние файлы и теги USLT/SYLT. `.lrc` и миллисекундные метки SYLT позволяют синхронизировать строки. |
| **Открыть .lrc / .txt** | Временно подставляет файл UTF-8 до 128 КБ для текущего трека. Тот же текст виден в «Сейчас играет» и в караоке; аудиофайл не меняется. |
| **Добавить свой текст…** | Временно подставляет вставленный текст или LRC. Без таймкодов строки не подсвечиваются по времени. |
| **LRCLIB** | По кнопке **Найти текст** передаёт название, исполнителя, а при наличии альбом и длительность. Ключ не нужен. Синхронный результат используется только при совпадении названия, исполнителя и длительности (±2 с). Если точный запрос не сработал, резервный поиск принимает только однозначное совпадение. Автопоиск выключен по умолчанию. |
| **Lyrics.ovh** | Выберите **Lyrics.ovh (только текст)** в источнике текста. Отправляются только исполнитель и название. Результат не подтверждает версию записи, не синхронизируется и не сохраняется в исходном файле. |
| **Викитека** | Для нескольких произведений показывает отдельно отмеченное исходное издание. Оно может отличаться от исполнения. Для обычных текстов и изданий Luma не придумывает таймкоды. |

**Сейчас играет → Оформление:** обложка, размытие, винил или центр. Компоновка выбирается независимо от фона. «Призма» вращается вокруг вертикальной оси; длинные линии «Спектра» и 17 «Столбцов» реагируют на локальный звук и плавно затихают на паузе. «Переливы Luma» используют цвет текущей обложки или акцент темы, если цвета обложки выключены. Вместо эффекта «Обложка на фоне» — «Тоннель» со световыми контурами; обычная компоновка «Обложка» осталась. Темп, яркость и реакция на звук настраиваются раздельно. Скрытые сцены и режим уменьшения движения не продолжают анимацию. Видимый предпросмотр в настройках позволяет оценить эффект без запуска песни. Видео волн уменьшено до 960×412, а холст ограничен 368 640 пикселями и 24–30 кадрами/с; для небольших сцен — 134 400 пикселей и 20 кадров/с.

**F** — большой плеер; **L** — караоке (обложка слева, синхронные строки справа); **Esc** — выход. **Ctrl+Shift+R** открывает и закрывает виджет, когда окно Luma в фокусе, без перезапуска воспроизведения. **Esc** также возвращает обычное окно. В теме **MacOS** мини-плеер использует матовый фон, кнопки окна слева и обложку рядом с управлением; выбранный фон можно посмотреть в **Настройки → Интеграции**. Клавиши **Пробел/K** запускают и ставят на паузу, **←/→** перематывают запись или переключают радио, **M** отключает звук, **Q** переключает очередь, **Ctrl+O** открывает файлы, **Ctrl+,** — настройки. Команды воспроизведения не перехватывают ввод в полях. Большой плеер использует то же воспроизведение; полноэкранный режим монитора можно отключить в **Настройки → Сейчас играет**.

## Параметрический эквалайзер

Откройте **Эквалайзер** в боковой панели, Dock темы MacOS или меню. Ползунки меняют усиление десяти полос. Нажмите на частоту под ползунком, чтобы настроить выбранную полосу: **частоту (20 Гц–20 кГц), тип фильтра, добротность Q и усиление**. Полки не используют Q, а режекторный фильтр не использует усиление. Полосу можно выключить, не сбрасывая значения.

Линия на графике показывает суммарную АЧХ фильтров с предусилением; столбцы — измеряемый спектр локального сигнала при воспроизведении. **Автозапас** рассчитывает, насколько снизить предусиление при подъёме частот; это не лимитер. Настройки сохраняются, существующие пять полос переносятся с их частотами и усилением. EQ применяется к локальным файлам и демотрекам, не к онлайн-потокам.

## Сервисы и ограничения

[Пошаговая инструкция](docs/services-setup.md) описывает настройку Last.fm, тексты, кэш, права на музыку и Float. Основные условия:

- **Last.fm** требует свой API Key, Shared Secret и отдельное согласие на отправку прослушиваний. С 0.14 ключи вводятся в **Настройки → Интеграции → Last.fm**, без PowerShell. Демо не отправляются; без сети скробблы не накапливаются.
- **Данные трека → Найти данные записи** ищет метаданные Apple Music, MusicBrainz или TheAudioDB (последние два — в Windows) без пользовательского ключа. MusicBrainz показывает варианты записи и доступный ISRC; TheAudioDB ищет по названию и исполнителю и показывает миниатюру для сравнения, не меняя обложку. Результаты не добавляются в онлайн-очередь. В Windows при настроенном `LUMA_ACOUSTID_CLIENT` можно искать по отпечатку: передаются отпечаток и длительность, а не аудиофайл. Ни один из этих каталогов метаданных не используется для воспроизведения.
- **Скачать MP3** в Windows работает для подходящих оригиналов Wikimedia Commons. Вместе с файлом сохраняется источник и лицензия. При включённой настройке синхронный текст сохраняется в отдельный `.lrc`, обычный — в тег нового MP3. Существующие файлы не перезаписываются. Лицензия на запись не означает автоматически лицензию на текст.
- **Локальный звук:** параметрический эквалайзер, кроссфейд 2–8 с между файлами, опциональный WASAPI Exclusive **Float32**. Float требует совместимого драйвера, при отказе используется системный вывод. Это не режим 24-bit integer и не обещание bit-perfect. Спектр, кроссфейд, EQ и Float не применяются к онлайн-потокам.
- **Windows:** системные медиаклавиши и метаданные через Media Session, компактный виджет поверх окон с десятью фонами, включая обложку альбома и матовое стекло. В **Настройки → Внешний вид** все темы применяются сразу; ручной выбор отключает автоматическое расписание. **MacOS** меняет компоновку, а не только цвета: навигация, плеер и очередь получают плавающие стеклянные панели в стиле Liquid Glass. **Меню → Диагностика** (`Ctrl+Shift+L`) показывает среду и локальный журнал до 300 событий. Пути к файлам, тексты, пароли, токены и названия треков в журнал не записываются. Экспорт отчёта запускает пользователь.

Профиль Windows: `%APPDATA%\Luma Player`; разработка использует отдельный `%APPDATA%\Luma Player Dev`. Удаление записи из медиатеки не удаляет аудиофайл с диска. В браузере файлы остаются в IndexedDB, если хранилище доступно. Экспериментировать без потери профиля можно в отдельной тестовой папке/профиле.

[Готовность Windows к 1.0.0 и необходимые разрешения сервисов](docs/windows-1.0-readiness.md).

## Сборка и проверка из исходников

Нужны Node.js **22.12+** и Git. Для собственного `.exe` — Windows, Visual Studio Build Tools с MSVC x64 и Windows SDK для вспомогательного WASAPI-процесса.

```powershell
git clone --single-branch --branch v1.2.0 https://github.com/JohnBirlich/VKX-Modded.git
cd VKX-Modded
npm.cmd ci
npm.cmd run dev
```

| Команда | Назначение |
| --- | --- |
| `npm.cmd run dev:web` | Веб-превью с музыкой, караоке и открытыми каталогами. Не проверяет интеграции Windows, Float, кэш и Last.fm. |
| `npm.cmd test` / `npm.cmd run typecheck` | Модульные тесты / проверки TypeScript рендерера и Electron. |
| `npm.cmd run build` / `npm.cmd run test:desktop` | Сборка и дымовой тест Electron во временном профиле: локальное и онлайн-аудио, караоке, темы, эквалайзер, `Ctrl+Shift+R`, очередь, полноэкранный режим, параллельный поиск, импорт локальных плейлистов, кэш и экспорт. |
| `npm.cmd run dist:win` / `npm.cmd run test:package` | Setup и Portable в `release/`; проверка состава ASAR, метаданных и версий. |
| `npm.cmd run test:installed` | Запуск Setup и Portable, системные ссылки, переустановка и удаление. Только на чистом Windows runner в GitHub Actions: меняет регистрацию приложения. |

CI по умолчанию подставляет детерминированные ответы каталогов. Ручные параметры **Windows build → live_catalog / live_services / live_radio** дополнительно проверяют каталоги, ответы сервисов метаданных и текстов или загрузку эфиров и логотипов. Ручные онлайн-проверки не публикуют артефакт. CI не проверяет реальный аккаунт Last.fm, закрытые данные VK или конкретный физический ЦАП.

**Публикация:** обновить версию `npm version <версия> --no-git-tag-version`, подготовить `docs/releases/<версия>.md`, дождаться успешного *push*-запуска **Windows build** для релизного коммита. Запустить **Publish Windows release** с тем же ref, `run_id` и подтверждённым `release_branch` (по умолчанию `main`). Workflow сверяет репозиторий, ветку и SHA, затем создаёт тег и прикладывает оба `.exe` и SHA-256.

`src/` — React и аудиологика, `electron/` — изолированный мост, библиотека и Windows, `native/windows/` — WASAPI, `tests/` — проверки. `scripts/media/` используется для регенерации демонстрационного звука и сцен, не при обычной сборке.
