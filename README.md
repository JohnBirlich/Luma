# Luma

Плеер для **Windows 10/11 x64**: локальная медиатека, музыкальные подборки, открытые каталоги, прямые эфиры и караоке. Подборки и «Сейчас играет» живут на **Главной** и используют общий плеер и очередь. Официальный сайт VK Музыки открывается в отдельной сессии внутри окна; его очередь не смешивается с очередью Luma, а записи из «Недавно в VK Музыке» играют, не уводя со экрана Luma.

**[Скачать последнюю версию](https://github.com/JohnBirlich/Luma/releases/latest)** · [Что нового в 1.6.0](docs/releases/1.6.0.md) · [Настройка сервисов с нуля](docs/services-setup.md)

Начиная с **1.5.0** приложение называется **Luma**. VK Музыка открывается сразу во вкладке, для нового входа используется официальный QR-код VK, а панель может переключать треки, менять позицию и держать состояние shuffle/repeat, пока сайт поддерживает эти команды.

## Установка

| Файл из релиза | Как запустить |
| --- | --- |
| **Luma Setup (Windows x64)** | Установите для текущего пользователя и запустите **Luma** из меню «Пуск». |
| `Luma-Portable-<версия>-x64.exe` | Запустите без установки. Данные сохраняются в профиле Windows, не рядом с `.exe`. |
| `SHA256SUMS.txt` | Сверьте SHA-256 нужного `.exe` с `Get-FileHash -Algorithm SHA256 .\имя-файла.exe` в PowerShell. |

Имя файла Setup в ссылке сохранено для проверки обновлений из прежних версий. Сборки не подписаны; Windows может показать предупреждение о неизвестном издателе. Скачивайте из релизов этого репозитория. Для обновления закройте Luma и установите новую версию: тот же профиль сохранит медиатеку, обложки, плейлисты, очередь и настройки. Установленная версия — **Меню → О приложении**. Русский и английский переключаются в **Настройки → Внешний вид**; язык данных (форматы и магазин Apple) настраивается отдельно.

При переходе с **1.5.6 или более ранней версии** скачайте [Setup или Portable](https://github.com/JohnBirlich/Luma/releases/latest) вручную: в этих сборках зашит адрес до переименования. Начиная с **1.5.8** проверка и скачивание используют постоянный ID репозитория, который не меняется при переименовании, поэтому 1.5.7 обновится до 1.5.8 сама, а дальше обновления снова автоматические.

## Музыка и медиатека

- **Главная → Для вас.** Микс Luma расположен рядом с «Сейчас играет» на широком окне и под ним на узком. Настройте микс по коллекции, избранному или истории; можно ограничить подборку файлами. Ниже — свои треки, жанры и настроения, а за ними подборки Luma и рекомендации из медиатеки. Откройте карточку, чтобы прослушать подборку, добавить результаты Jamendo или сохранить плейлист. Приложение использует реальные теги и локальную историю; оно не угадывает отсутствующие жанры и не добавляет вымышленную историю или друзей. «Не рекомендовать» исключает трек из подборок, но не удаляет его из коллекции.
- **Обновления приложения.** Отдельной вкладки на Главной больше нет: быстрый доступ открывает страницу **Настройки → Обновления приложения** с проверкой релизов и недавно импортированными файлами. С 1.5.2 Luma скачивает подходящий Setup или Portable с прогрессом и проверкой SHA-256; запуск из приложения по-прежнему требует подписанного Setup с закреплённым сертификатом. Быстрые ссылки «Для вас», «Моя музыка» и «VK Музыка» из панели убраны — она ведёт только в настройки. Если на GitHub вышел новый релиз, рядом с «Обновлениями» в быстром доступе и в самом разделе настроек горит оранжевая пульсирующая точка: проверка повторяется при возврате к окну, появлении сети и после неудачного запроса.
- **Импорт из сервисов.** Кнопка на Главной рядом с **Добавить музыку** открывает мастер импорта плейлиста: выберите источник, откройте файл экспорта и проверьте совпадения. Для каждой строки выберите доступный трек или пропустите её; плейлист сохраняется только по подтверждению. Вход в аккаунт и скачивание аудио не выполняются. Нижний пункт **Плейлист из M3U** — файловый вариант с собственной подписью: обычный список или расширенный M3U/M3U8 с `#EXTINF`, из которого Luma читает только названия и исполнителей.
- **Моя музыка.** Создавайте и редактируйте локальные плейлисты, переносите треки в «Любимое Luma» без изменения лайков в других сервисах.
- **Поиск на Главной или отдельная вкладка «Поиск».** Один запрос ищет в медиатеке и подключённых каталогах. В веб-версии и Windows это Jamendo и Wikimedia Commons через [Openverse](https://openverse.org/). В Windows также доступны Internet Archive Netlabels (включая подборку Southern City’s Lab), [Audius](https://audius.co/) и [прямой Jamendo](docs/services-setup.md#jamendo-напрямую-и-genius) с зарегистрированным Client ID. Прямой Jamendo показывает дополнительные записи из того же каталога, не дублируя найденные Openverse. Для концертных записей [Phish.in](https://phish.in/api-docs) введите `Phish` и точное название песни, например `Phish Llama`. Совместимые записи показываются вместе с вариантами источника. Ввод с Enter и выбранные результаты добавляются в очищаемую локальную историю поиска. Выдача обновляется по мере поступления ответов; один сбой не скрывает другие записи. В компактном блоке **Источники** видно, где нет совпадений, а где помешал сбой или лимит. Повтор ищет только в источниках, которые не завершили запрос. Если отключить **Автопоиск**, останутся поиск по устройству и ручной онлайн-запрос. [Условия и ограничения источников](docs/services-setup.md#радио-поиск-по-каталогам-и-плейлисты).
- **Радио.** Ярлык под эквалайзером, в стеклянном доке и в заголовке узкого окна открывает **Главная → Радио** без запуска эфира. В каталоге 96 станций в заданном порядке, плюс каналы Record и SomaFM отдельным блоком. Для 85 станций используются логотипы из каталога Единого радиоплеера; если логотип недоступен, Luma рисует свою обложку. В настольной Luma вид **Поиск станций** запрашивает Radio Browser по названию, стране, языку и тегу; совместимые HTTPS-эфиры запускаются в Luma, остальные открываются в браузере. Ищите по названию и жанру: **В Luma** — прямой поток, **В браузере** — ссылка на эфир у источника. Кнопка **+** сохраняет станцию без запуска эфира. **Добавленные** — отдельный вид каталога, чтобы сохранённая станция не появлялась на экране дважды. При прослушивании **Предыдущая / Следующая** или **←/→** переключают прямые эфиры по кругу в порядке всего каталога, пропуская станции без потока. Посещённые станции не накапливаются в очереди. Поток идёт напрямую от вещателя; перемотки внутри эфира, кэша, экспорта, текстов и скробблинга нет.
- **Медиатека.** Добавляйте файлы кнопкой или перетаскиванием: MP3, WAV, FLAC, OGG/OGA, OPUS, M4A, AAC, WEBM. Воспроизведение зависит от кодека. Локальные файлы не загружаются на сервер и не копируются в Windows. Доступны список/плитка, избранное, до 60 недавних записей и **Без сети** для локальных файлов и демо. Обложка и правки названия/исполнителя сохраняются в профиле, а не в исходном файле.
- **Онлайн-записи.** Можно слушать и ставить в очередь без добавления в медиатеку. У поддерживаемых источников можно сохранить ссылку в **Из интернета**; Audius, прямой Jamendo и Phish.in доступны только в текущей сессии. **Перенос музыки → Импорт онлайн-трека** принимает ссылки Openverse на поддерживаемые источники. Jamendo: MP3 96 кбит/с, MP3 VBR или вариант каталога, отдельный профиль для лимитной сети. Другие источники — оригинал. Для разрешённых MP3 Wikimedia Commons в Windows доступен временный кэш (32 МиБ на трек, 128 МиБ суммарно, до 14 дней). Копию можно слушать без сети из **Из интернета**; очистка кэша не удаляет ссылки.
- **Обмен и избранное.** Кнопка «Поделиться» сохраняет трек или список в файл `.luma.json` без аудио и приватных путей, а у поддерживаемой записи Openverse копирует ссылку для Luma. Таймер сна доступен на карточке «Сейчас играет». Discord Rich Presence включён сразу: в приложение встроен собственный публичный Application ID, поэтому в «Интеграциях» больше нет карточки настройки, а локальному Discord передаются только название и исполнитель текущего трека — без путей, истории и ссылок.

### VK Музыка

Откройте **Главная → VK Музыка**: официальный сайт появится сразу. Если VK попросит войти, отсканируйте QR-код на его странице: на экране входа остаётся только карточка с кодом — шапка VK, поиск, ссылка «Создать страницу для бизнеса», боковые панели и нижние тексты скрыты, а карточка масштабируется под размер окна, поэтому QR видно целиком и в узком, и в низком окне. Данные входа обрабатывает VK, а сессия сохраняется в профиле приложения. Над сайтом остаются кнопки навигации и сброса входа. Музыкой можно управлять в нативном плеере VK или в «Сейчас играет». Доступ к записям, реклама и ограничения определяются VK.

Для страниц VK Музыки всегда используется вид **Без панелей**: левое меню, общая шапка и список чатов скрыты, а музыкальные разделы и плеер остаются. Компактный плеер VK подменяет полный, когда тот не виден. Страницы входа и другие разделы VK не меняются.

**«Недавно в VK Музыке» — это плеер, а не ссылки.** Клик по записи загружает её страницу внутри гостевой сессии и нажимает транспорт VK: трек звучит, а экран Luma остаётся там, где был. Меню записи даёт четыре действия и выполняет их теми же кнопками, что и сайт: **Добавить в мою музыку**, **Не нравится**, **Открыть альбом** (альбом открывается в гостевой сессии) и **Скопировать ссылку** с подтверждением «Ссылка скопирована». Если VK не отдал действие, Luma сообщает об этом, а не притворяется, что всё получилось.

Запущенный на сайте трек отображается в **«Сейчас играет»**, нижней панели, большом плеере и виджете. Обложка берётся из текущего трека VK. Пауза, переключение, перемотка и громкость передаются плееру VK, если сайт их поддерживает. **Перемешать очередь** и **Повтор трека** держат состояние: принятое VK нажатие остаётся включённым в Luma до конца трека, а отклонённое возвращает кнопку назад с уведомлением. Можно уйти с вкладки или свернуть окно: звук остаётся в официальной сессии. Закрытие сайта или запуск собственного источника Luma прекращает воспроизведение VK. Записи VK не попадают в очередь, миксы или файлы Luma.

**Искать в VK Музыке** передаёт запрос только по нажатию. **Открыть музыкальную ссылку** принимает обычную ссылку на трек или плейлист VK; код виджета не нужен. [Вход, управление и сброс сессии](docs/services-setup.md#vk-официальный-сайт-внутри-luma).

Отдельный **Импорт из сервисов → VK Музыка** по-прежнему принимает CSV или TXT и сопоставляет список с локальной медиатекой, не загружая песни. Старые данные закладок остаются в профиле.

## Караоке и оформление

Нажмите микрофон на карточке трека или в нижнем плеере. **Караоке** ставит обложку и управление слева, а текст — справа. В узком окне колонки складываются. Выбранная сцена может оставаться на фоне, а режим «Обложка» заменяется мягким фоном. В теме **MacOS** это относится и к большому плееру. Доступны исполнитель, таймлайн, транспорт, громкость, очередь и эквалайзер. При наличии меток времени выделяется текущая строка, а если LRCLIB вернул точные метки слов — и текущее слово. Нажмите на строку, чтобы перемотать к ней. В **Настройках текста** можно выключить автопрокрутку, изменить размер, толщину, интервал и выравнивание. Оформление сохраняется между запусками. Текст можно выделить и скопировать; подписи меню, боковой панели и кнопок не выделяются.

| Источник текста | Что делает Luma |
| --- | --- |
| Соседний `.lrc`, `.lyrics.txt` или теги файла | В Windows читает соседние файлы и теги USLT/SYLT. `.lrc` и миллисекундные метки SYLT позволяют синхронизировать строки. |
| **Открыть .lrc / .txt** | Временно подставляет файл UTF-8 до 128 КБ для текущего трека. Тот же текст виден в «Сейчас играет» и в караоке; аудиофайл не меняется. |
| **Добавить свой текст…** | Временно подставляет вставленный текст или LRC. Без таймкодов строки не подсвечиваются по времени. |
| **LRCLIB** | По кнопке **Найти текст** передаёт название, исполнителя, а при наличии альбом и длительность. Ключ не нужен. Синхронный результат используется только при совпадении названия, исполнителя и длительности (±2 с). Если точный запрос не сработал, резервный поиск принимает только однозначное совпадение. Автопоиск выключен по умолчанию. |
| **Lyrics.ovh** | Выберите **Lyrics.ovh (только текст)** в источнике текста. Отправляются только исполнитель и название. Результат не подтверждает версию записи, не синхронизируется и не сохраняется в исходном файле. |
| **Викитека** | Для нескольких произведений показывает отдельно отмеченное исходное издание. Оно может отличаться от исполнения. Для обычных текстов и изданий Luma не придумывает таймкоды. |

**Сейчас играет → Оформление:** обложка, размытие, винил или центр. Компоновка выбирается независимо от фона. **«Спектр»** перерисован заново: несколько длинных разноцветных линий текут по полотну, следуют за живыми частотами, пересекаются и плавно затухают вместе со звуком. **«Кристаллы»** (прежние «Ленты») растут гранёными шардами в такт 17 полосам. **«Хромолинии»** растягивают оба слоя на весь кадр и перетекают друг в друга мягкими масками. **«Сияние»** вернуло прежнее северное сияние с плавными полотнищами и подсвеченной кромкой. «Призма» вращается вокруг вертикальной оси. «Переливы Luma» используют цвет текущей обложки или акцент темы, если цвета обложки выключены. Вместо эффекта «Обложка на фоне» — «Тоннель» со световыми контурами; обычная компоновка «Обложка» осталась. Темп, яркость и реакция на звук настраиваются раздельно. Скрытые сцены и режим уменьшения движения не продолжают анимацию. Фоновые сцены, включая более яркие «Звёзды», продолжают двигаться на паузе в плеере и виджете рабочего стола. «Спектр», «Кристаллы» и «Импульс» затихают вместе со звуком. Смена обложки в плеере, списках, очереди и виджете — кроссфейд: новая картинка проявляется поверх прежней. Предпросмотр виджета в настройках показывает выбранный эффект. Список **Виджеты рабочего стола → Фон** предлагает те же сцены, что и **Эффекты**, вместе с «Жидким стеклом»: оно возвращается как отдельный эффект и включается само при выборе темы **MacOS**. Холсты учитывают плотность экрана и ограничены примерно 2,07 млн пикселей и 24–30 кадрами/с; небольшие сцены — до 460 800 пикселей и 20 кадров/с.

**F** — большой плеер; **L** — караоке (обложка слева, синхронные строки справа); **Esc** — выход. **Ctrl+Shift+R** открывает и закрывает виджет, когда окно Luma в фокусе, без перезапуска воспроизведения. **Esc** также возвращает обычное окно. В теме **MacOS** мини-плеер использует матовый фон, кнопки окна слева и обложку рядом с управлением; выбранный фон можно посмотреть в **Настройки → Интеграции**. Клавиши **Пробел/K** запускают и ставят на паузу, **←/→** перематывают запись или переключают радио, **M** отключает звук, **Q** переключает очередь, **Ctrl+O** открывает файлы, **Ctrl+,** — настройки. Команды воспроизведения не перехватывают ввод в полях. Большой плеер использует то же воспроизведение; полноэкранный режим монитора можно отключить в **Настройки → Сейчас играет**.

## Статистика, диагностика и меню

- **Статистика** стоит перед «О приложении» и собирает цифры в одном месте: сколько треков запущено с устройства, сколько — в Музыке VK, общее число и время в плеере, дату первого прослушивания, размер медиатеки (файлы, онлайн-треки, плейлисты, избранное) и число записей в истории. «Время в плеере» тикает каждую секунду. Отдельный блок **Аккаунты** показывает состояние входа: **Аккаунт VK** — «Подключено» или «Не подключено» с тем же индикатором, что в «Диагностике», а **Аккаунт Spotify** и **Аккаунт Яндекс Музыки** помечены как «Временно недоступно» до появления входов. Заголовок раздела стоит рядом со стрелкой возврата, как в остальных разделах. Всё считается на этом устройстве и никуда не отправляется.
- **Диагностика** (`Ctrl+Shift+L`) показывает версию, систему и **Интернет Соединение** в одном ряду; индикатор связи светится неоновым ореолом и пульсирует, пока сеть доступна. Журнал пишется файлом в профиль Luma и хранит до 1000 записей, а на экране видны последние 300. Уровень, время и текст события стоят в отдельных колонках и не наслаиваются даже на узком окне; в карточке связи подпись, значение и пояснение выстроены так же, как у «Версии» и «Системы». Фильтры: область (запуск, подключение, медиатека, воспроизведение, интерфейс) и уровень — **Информация**, **Предупреждение**, **Ошибка**, **Критический сбой** плюс сборный пункт «Все сбои». Пути к файлам, тексты, пароли, токены и названия треков в журнал не записываются. Экспорт отчёта запускает пользователь.
- **Стрелки «назад»** стоят слева в каждом разделе и на каждой странице настроек.

## Параметрический эквалайзер

Откройте **Эквалайзер** в боковой панели, Dock темы MacOS или меню. Ползунки меняют усиление десяти полос. Нажмите на частоту под ползунком, чтобы настроить выбранную полосу: **частоту (20 Гц–20 кГц), тип фильтра, добротность Q и усиление**. Полки не используют Q, а режекторный фильтр не использует усиление. Полосу можно выключить, не сбрасывая значения.

Линия на графике показывает суммарную АЧХ фильтров с предусилением; столбцы — измеряемый спектр локального сигнала при воспроизведении. **Автозапас** рассчитывает, насколько снизить предусиление при подъёме частот; это не лимитер. Настройки сохраняются, существующие пять полос переносятся с их частотами и усилением. EQ применяется к локальным файлам и демотрекам, не к онлайн-потокам.

## Сервисы и ограничения

[Пошаговая инструкция](docs/services-setup.md) описывает настройку Last.fm, текстов, кэша, прав на музыку и Float. Основные условия:

- **ListenBrainz** подключается отдельным личным токеном, отправка выключена по умолчанию. После согласия новые прослушивания локальных треков публикуются в истории ListenBrainz. **Genius** по токену показывает аннотации в данных трека, а **Openwhyd** импортирует публичный список по ссылке для сопоставления с медиатекой. Они не дают доступа к музыкальным потокам. [Настройка и приватность](docs/services-setup.md).
- **Last.fm** требует свой API Key, Shared Secret и отдельное согласие на отправку прослушиваний. Ключи вводятся в **Настройки → Интеграции → Last.fm**, без PowerShell. Демо не отправляются; без сети скробблы не накапливаются.
- **Данные трека → Найти данные записи** ищет метаданные Apple Music, MusicBrainz или TheAudioDB (последние два — в Windows) без пользовательского ключа. MusicBrainz показывает варианты записи и доступный ISRC; TheAudioDB ищет по названию и исполнителю и показывает миниатюру для сравнения, не меняя обложку. Результаты не добавляются в онлайн-очередь. В Windows при настроенном `LUMA_ACOUSTID_CLIENT` можно искать по отпечатку: передаются отпечаток и длительность, а не аудиофайл. Ни один из этих каталогов метаданных не используется для воспроизведения.
- **Скачать MP3** в Windows работает для подходящих оригиналов Wikimedia Commons. Вместе с файлом сохраняется источник и лицензия. При включённой настройке синхронный текст сохраняется в отдельный `.lrc`, обычный — в тег нового MP3. Существующие файлы не перезаписываются. Лицензия на запись не означает автоматически лицензию на текст.
- **Плавное переключение:** название, цвет и готовая обложка в «Сейчас играет» проявляются плавно, если включена анимация. Кроссфейд 2–8 с отдельно включается в **Настройки → Воспроизведение**. Работает при ручной и автоматической смене файлов и подходящих онлайн-записей с известной длительностью. Если вторая запись не успела загрузиться, используется обычный переход. VK, радио, повтор той же записи и подгрузка на лимитной сети не используют наложение. При Float-выводе наложение возможно только в пределах одного звукового тракта.
- **Локальный звук:** параметрический эквалайзер, спектр и опциональный WASAPI Exclusive **Float32**. Float требует совместимого драйвера, при отказе используется системный вывод. Это не режим 24-bit integer и не обещание bit-perfect. Эквалайзер, спектр и Float не обрабатывают онлайн-потоки.
- **Windows:** системные медиаклавиши и метаданные через Media Session, компактный виджет поверх окон с десятью фонами, включая обложку альбома и матовое стекло. В **Настройки → Внешний вид** все темы применяются сразу; ручной выбор отключает автоматическое расписание. **MacOS** меняет компоновку, а не только цвета: навигация, плеер и очередь получают плавающие стеклянные панели в стиле Liquid Glass.

Чтобы сохранить данные при обновлении, Luma использует прежний профиль Windows `%APPDATA%\Luma Player`; разработка использует отдельный `%APPDATA%\Luma Player Dev`. Диагностический журнал лежит в `logs\diagnostics.json` этого профиля. Удаление записи из медиатеки не удаляет аудиофайл с диска. В браузере файлы остаются в IndexedDB, если хранилище доступно. Экспериментировать без потери профиля можно в отдельной тестовой папке/профиле.

[Готовность Windows к 1.0.0 и необходимые разрешения сервисов](docs/windows-1.0-readiness.md).

## Сборка и проверка из исходников

Нужны Node.js **22.12+** и Git. Для собственного `.exe` — Windows, Visual Studio Build Tools с MSVC x64 и Windows SDK для вспомогательного WASAPI-процесса.

```powershell
git clone --single-branch --branch v1.6.0 https://github.com/JohnBirlich/Luma.git
cd Luma
npm.cmd ci
npm.cmd run dev
```

| Команда | Назначение |
| --- | --- |
| `npm.cmd run dev:web` | Веб-превью с музыкой, караоке и открытыми каталогами. Не проверяет интеграции Windows, Float, кэш и Last.fm. |
| `npm.cmd test` / `npm.cmd run typecheck` | Модульные тесты / проверки TypeScript рендерера и Electron. |
| `npm.cmd run build` / `npm.cmd run test:desktop` | Сборка и дымовой тест Electron во временном профиле: локальное и онлайн-аудио, караоке, темы, эффекты, эквалайзер, `Ctrl+Shift+R`, очередь, полноэкранный режим, параллельный поиск, изолированный сайт VK с тестовым аудио, импорт локальных плейлистов, кэш и экспорт. |
| `npm.cmd run dist:win` / `npm.cmd run test:package` | Setup и Portable в `release/`; проверка состава ASAR, метаданных и версий. |
| `npm.cmd run test:installed` | Запуск Setup и Portable, системные ссылки, переустановка и удаление. Только на чистом Windows runner в GitHub Actions: меняет регистрацию приложения. |

CI по умолчанию подставляет детерминированные ответы каталогов. Ручные параметры **Windows build → live_catalog / live_services / live_radio** дополнительно проверяют каталоги, ответы сервисов метаданных и текстов или загрузку эфиров и логотипов. Ручные онлайн-проверки не публикуют артефакт. Проверка VK в CI моделирует QR-вход, возврат к плейлисту, переключение, перемотку и меню записи без реального аккаунта. Проверка установки обновляет опубликованную 1.4.0 до новой сборки, сохраняя профиль и ассоциацию ссылок. CI также не проверяет реальный аккаунт Last.fm или конкретный физический ЦАП.

**Публикация:** обновить версию `npm version <версия> --no-git-tag-version`, подготовить `docs/releases/<версия>.md`, дождаться успешного *push*-запуска **Windows build** для релизного коммита. Запустить **Publish Windows release** с тем же ref, `run_id` и подтверждённым `release_branch` (по умолчанию `main`). Workflow сверяет репозиторий, ветку и SHA, затем создаёт тег и прикладывает оба `.exe` и SHA-256.

`src/` — React и аудиологика, `electron/` — изолированный мост, библиотека и Windows, `native/windows/` — WASAPI, `tests/` — проверки. `scripts/media/` используется для регенерации демонстрационного звука и сцен, не при обычной сборке.
