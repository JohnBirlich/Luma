# Luma Player

Плеер для **Windows 10/11 x64**: локальная медиатека, музыкальные подборки, открытые каталоги, прямые эфиры и караоке. Музыкальные подборки и «Сейчас играет» находятся на **Главной** и используют общий плеер и очередь. Luma не подключается к личной аудиотеке VK и не воспроизводит потоки VK.

**[Скачать 0.16.0](https://github.com/JohnBirlich/VKX-Modded/releases/tag/v0.16.0)** · [Что нового](docs/releases/0.16.0.md) · [Настройка сервисов с нуля](docs/services-setup.md)

## Установка

| Файл из Assets | Как запустить |
| --- | --- |
| `Luma-Player-Setup-0.16.0-x64.exe` | Установите для текущего пользователя и запустите **Luma Player** из меню «Пуск». |
| `Luma-Player-Portable-0.16.0-x64.exe` | Запустите без установки. Данные сохраняются в профиле Windows, не рядом с `.exe`. |
| `SHA256SUMS.txt` | Сверьте SHA-256 нужного `.exe` с `Get-FileHash -Algorithm SHA256 .\имя-файла.exe` в PowerShell. |

Сборки не подписаны; Windows может показать предупреждение о неизвестном издателе. Скачивайте из релизов этого репозитория. Для обновления закройте Luma и установите новую версию: тот же профиль сохранит файлы в медиатеке, обложки, очередь, закладки и настройки. Установленная версия — **Меню → О приложении**, сразу под **Эквалайзером**. Русский и английский переключаются в **Настройки → Внешний вид**. Язык данных (форматы и магазин Apple) настраивается отдельно.

## Музыка и медиатека

Автопоиск и импорт списка треков VK описаны для ветки разработки. В опубликованной 0.16.0 поиск по каталогу запускается вручную, а VK представлен закладками.

- **Главная → Для вас.** Под карточкой «Сейчас играет» запустите микс Luma или настройте его по коллекции, избранному или истории; можно ограничить подборку файлами. Ниже — свои треки, открытия, похожие записи, жанры, настроения и десять оригинальных демотреков. Приложение использует реальные теги и локальную историю; не угадывает отсутствующие жанры и не добавляет вымышленную историю или друзей. «Не рекомендовать» исключает трек из подборок, но не удаляет его из коллекции.
- **Моя музыка / Обзор / Обновления.** Создавайте и редактируйте локальные плейлисты в «Моей музыке». В «Обзоре» можно открыть жанр, настроение или подборку, добавить результаты Jamendo, запустить список или сохранить его как плейлист. В «Обновлениях» — недавно импортированные файлы и ссылка на релизы. Обновление устанавливается вручную.
- **Поиск на Главной или отдельная вкладка «Поиск».** Один запрос ищет в медиатеке, импортированном списке VK и автоматически во всех подключённых открытых каталогах. В веб-версии и Windows это Jamendo и Wikimedia Commons через [Openverse](https://openverse.org/); в Windows — также Internet Archive Netlabels и Southern City’s Lab. Результаты с указанием источника и лицензии появляются по мере готовности. При недоступности одного каталога результаты остальных остаются. Если нужен поиск только на устройстве, выключите **Автоматический онлайн-поиск**. В свёрнутом блоке **Открыть на музыкальных сайтах** остаются ссылки на VK Музыку, Музыку Mail.ru, Яндекс Музыку, Zvuch, DriveMusic и Muzika.fun. Эти сайты не входят в выдачу Luma.
- **Главная → Радио.** Выберите жанр и нажмите кнопку воспроизведения станции Radio Record или SomaFM. Кнопка **+** сохраняет станцию в «Добавленных». Поток идет напрямую от вещателя; перемотки, кэша, экспорта, текстов и скробблинга для эфиров нет.
- **Медиатека.** Добавляйте файлы кнопкой или перетаскиванием: MP3, WAV, FLAC, OGG/OGA, OPUS, M4A, AAC, WEBM. Воспроизведение зависит от кодека. Локальные файлы не загружаются на сервер и не копируются в Windows. Доступны список/плитка, избранное, до 60 недавних записей и **Без сети** для локальных файлов и демо. Обложка и правки названия/исполнителя сохраняются в профиле, не в исходном файле.
- **Онлайн-записи.** Можно слушать и ставить в очередь без добавления в медиатеку или сохранить ссылку в **Из интернета**. **Перенос музыки → Импорт онлайн-трека** принимает ссылки Openverse на поддерживаемые источники. Jamendo: MP3 96 кбит/с, MP3 VBR или вариант каталога, отдельный профиль для лимитной сети. Другие источники — оригинал. Для разрешённых MP3 Wikimedia Commons в Windows доступен временный кэш (32 МиБ на трек, 128 МиБ суммарно, до 14 дней). Копию можно слушать без сети из **Из интернета**; очистка кэша не удаляет ссылки.

### Мои треки и закладки VK

**Главная → Моя музыка → Мои треки из VK** принимает список CSV или TXT. Записи остаются в профиле Luma и находятся в поиске даже без сети. Это импорт названий, исполнителей и альбомов, а не синхронизация VK. Чтобы воспроизвести трек из списка, нужен соответствующий локальный аудиофайл в медиатеке Luma. [Формат файла и ограничения](docs/services-setup.md#vk-моя-музыка-и-рекомендации).

**Главная → Моя музыка → Закладки VK** сохраняет старые ссылки и обложки. **Добавить закладку** принимает ссылку «Поделиться» либо код виджета из официального генератора: Luma извлекает только адрес/идентификаторы, не исполняет код. **Открыть в VK** передаёт ссылку обычному браузеру. Для входа, личной музыки, VK Микса, подборок друзей и редакции нужен сам сервис. Luma их не запрашивает, не воспроизводит и не кэширует потоки VK. Старую сессию встроенного сайта можно удалить кнопкой под списком закладок, не затрагивая браузер или сохранённые ссылки.

## Караоке и оформление

Нажмите микрофон на карточке трека или в нижнем плеере. **Караоке** показывает небольшую обложку рядом с текстом, без дубликата обложки на весь экран. Выбранная сцена может оставаться на фоне, а режим «Обложка» заменяется мягким фоном. В теме **MacOS** это относится и к большому плееру. Доступны исполнитель, таймлайн, транспорт, громкость, очередь и эквалайзер. При наличии меток времени выделяется текущая строка; она меняется при перемотке и переходе к другому треку. Автопрокрутку можно выключить для чтения. Текст можно выделить и скопировать; подписи меню, боковой панели и кнопок не выделяются.

| Источник текста | Что делает Luma |
| --- | --- |
| Соседний `.lrc`, `.lyrics.txt` или теги файла | В Windows читает соседние файлы и теги USLT/SYLT. `.lrc` и миллисекундные метки SYLT позволяют синхронизировать строки. |
| **Открыть .lrc / .txt** | Временно подставляет файл UTF-8 до 128 КБ для текущего трека. Тот же текст виден в «Сейчас играет» и в караоке; аудиофайл не меняется. |
| **LRCLIB** | По кнопке **Найти текст** передаёт название, исполнителя, а при наличии альбом и длительность. Синхронный результат используется только при совпадении записи по метаданным и длительности. Автопоиск выключен по умолчанию. |
| **Викитека** | Для нескольких произведений показывает отдельно отмеченное исходное издание. Оно может отличаться от исполнения. Для обычных текстов и изданий Luma не придумывает таймкоды. |

**Сейчас играет → Оформление:** обложка, размытие, винил или центр; отдельная обложка на фоне и набор сцен от Сияния и Призмы до Дождя, Спектра, Нот и Метеоров, плюс режим без эффекта. Темп, яркость и реакция на локальный звук настраиваются раздельно. Анимируется видимая сцена; при паузе «Импульс» и «Метеоры» плавно затихают. Скрытые сцены и режим уменьшения движения не продолжают анимацию. Исключение — видимый предпросмотр настройки: он позволяет оценить эффект без запуска песни. Видео волн уменьшено до 960×412, а холст ограничен 368 640 пикселями и 24–30 кадрами/с; для небольших сцен — 134 400 пикселей и 20 кадров/с.

**F** — большой плеер; **L** — караоке (обложка слева, синхронные строки справа); **Esc** — выход. **Ctrl+Shift+R** открывает и закрывает виджет, когда окно Luma в фокусе, без перезапуска воспроизведения. **Esc** также возвращает обычное окно. Клавиши **Пробел/K** запускают и ставят на паузу, **←/→** перематывают, **M** отключает звук, **Q** переключает очередь, **Ctrl+O** открывает файлы, **Ctrl+,** — настройки. Команды воспроизведения не перехватывают ввод в полях. Большой плеер использует то же воспроизведение; полноэкранный режим монитора можно отключить в **Настройки → Сейчас играет**.

## Параметрический эквалайзер

Откройте **Эквалайзер** в боковой панели, Dock темы MacOS или меню. Ползунки меняют усиление десяти полос. Нажмите на частоту под ползунком, чтобы настроить выбранную полосу: **частоту (20 Гц–20 кГц), тип фильтра, добротность Q и усиление**. Полки не используют Q, а режекторный фильтр не использует усиление. Полосу можно выключить, не сбрасывая значения.

Линия на графике показывает суммарную АЧХ фильтров с предусилением; столбцы — измеряемый спектр локального сигнала при воспроизведении. **Автозапас** рассчитывает, насколько снизить предусиление при подъёме частот; это не лимитер. Настройки сохраняются, существующие пять полос переносятся с их частотами и усилением. EQ применяется к локальным файлам и демотрекам, не к онлайн-потокам.

## Сервисы и ограничения

[Пошаговая инструкция](docs/services-setup.md) описывает настройку Last.fm, тексты, кэш, права на музыку и Float. Основные условия:

- **Last.fm** требует свой API Key, Shared Secret и отдельное согласие на отправку прослушиваний. С 0.14 ключи вводятся в **Настройки → Интеграции → Last.fm**, без PowerShell. Демо не отправляются; без сети скробблы не накапливаются.
- **Данные трека** ищут метаданные Apple Music; рекламные обложки и превью не используются. В Windows при настроенном `LUMA_ACOUSTID_CLIENT` можно искать по отпечатку: передаются отпечаток и длительность, а не аудиофайл. Musixmatch, Genius и закрытые аудио API VK не подключены.
- **Скачать MP3** в Windows работает для подходящих оригиналов Wikimedia Commons. Вместе с файлом сохраняется источник и лицензия. При включённой настройке синхронный текст сохраняется в отдельный `.lrc`, обычный — в тег нового MP3. Существующие файлы не перезаписываются. Лицензия на запись не означает автоматически лицензию на текст.
- **Локальный звук:** параметрический эквалайзер, кроссфейд 2–8 с между файлами, опциональный WASAPI Exclusive **Float32**. Float требует совместимого драйвера, при отказе используется системный вывод. Это не режим 24-bit integer и не обещание bit-perfect. Спектр, кроссфейд, EQ и Float не применяются к онлайн-потокам.
- **Windows:** системные медиаклавиши и метаданные через Media Session, компактный виджет поверх окон с девятью фонами, включая обложку альбома и матовое стекло. В **Настройки → Внешний вид** все темы применяются сразу; ручной выбор отключает автоматическое расписание. **MacOS** меняет компоновку, а не только цвета: навигация, плеер и очередь получают плавающие стеклянные панели в стиле Liquid Glass. **Меню → Диагностика** (`Ctrl+Shift+L`) показывает среду и локальный журнал до 300 событий. Пути к файлам, тексты, пароли, токены и названия треков в журнал не записываются. Экспорт отчёта запускает пользователь.

Профиль Windows: `%APPDATA%\Luma Player`; разработка использует отдельный `%APPDATA%\Luma Player Dev`. Удаление записи из медиатеки не удаляет аудиофайл с диска. В браузере файлы остаются в IndexedDB, если хранилище доступно. Экспериментировать без потери профиля можно в отдельной тестовой папке/профиле.

## Сборка и проверка из исходников

Нужны Node.js **22.12+** и Git. Для собственного `.exe` — Windows, Visual Studio Build Tools с MSVC x64 и Windows SDK для вспомогательного WASAPI-процесса.

```powershell
git clone --single-branch --branch v0.16.0 https://github.com/JohnBirlich/VKX-Modded.git
cd VKX-Modded
npm.cmd ci
npm.cmd run dev
```

| Команда | Назначение |
| --- | --- |
| `npm.cmd run dev:web` | Веб-превью с музыкой, караоке и открытыми каталогами. Не проверяет интеграции Windows, Float, кэш и Last.fm. |
| `npm.cmd test` / `npm.cmd run typecheck` | Модульные тесты / проверки TypeScript рендерера и Electron. |
| `npm.cmd run build` / `npm.cmd run test:desktop` | Сборка и дымовой тест Electron во временном профиле: локальное и онлайн-аудио, караоке, темы, эквалайзер, `Ctrl+Shift+R`, очередь, полноэкранный режим, параллельный поиск, импорт списка VK, закладки, кэш и экспорт. |
| `npm.cmd run dist:win` / `npm.cmd run test:package` | Setup и Portable в `release/`; проверка состава ASAR, метаданных и версий. |

CI по умолчанию подставляет детерминированные ответы каталогов. Ручные параметры **Windows build → live_catalog / live_services / live_radio** дополнительно проверяют каталоги, запросы Apple/LRCLIB или загрузку эфиров и логотипов. Ручная проверка радио не публикует артефакт. CI не проверяет реальный аккаунт Last.fm, закрытые данные VK или конкретный физический ЦАП.

**Публикация:** обновить версию `npm version <версия> --no-git-tag-version`, подготовить `docs/releases/<версия>.md`, дождаться успешного *push*-запуска **Windows build** для релизного коммита. Запустить **Publish Windows release** с тем же ref, `run_id` и подтверждённым `release_branch` (по умолчанию `main`). Workflow сверяет репозиторий, ветку и SHA, затем создаёт тег и прикладывает оба `.exe` и SHA-256.

`src/` — React и аудиологика, `electron/` — изолированный мост, библиотека и Windows, `native/windows/` — WASAPI, `tests/` — проверки. `scripts/media/` используется для регенерации демонстрационного звука и сцен, не при обычной сборке.
