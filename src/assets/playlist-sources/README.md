# Playlist import marks

These assets are bundled locally so the source picker needs no network access. They identify file sources, not account integrations or endorsements. Names and marks belong to their respective owners.

- Spotify, Apple Music, SoundCloud and TIDAL: [Simple Icons 16.38.0](https://www.npmjs.com/package/simple-icons/v/16.38.0), CC0-1.0. Paths are rendered in brand colors with backing shapes where needed for contrast.
- Deezer equalizer mark: [Simple Icons 9.21.0](https://www.npmjs.com/package/simple-icons/v/9.21.0), CC0-1.0. This is the mark shown in the reference.
- Yandex Music: [2023 icon by Yandex LLC on Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Yandex_Music_icon_2023.svg), marked public domain (simple geometry); resized to a local PNG.
